## 二、四条可迁移的结构规则

### 规则 1：首页"投资要点"4–6 条，每条一个完整论证

出处：532079 第 2 页、531931 第 2 页、531998 第 2–3 页、532198 第 2 页。

固定结构：

```
◼ {结论句}。{论据：数字 + 同比/环比 + 时间}。{含义或推论}。
◼ ……
◼ 投资分析意见：{推荐标的与理由}
◼ 风险提示：{风险 1}；{风险 2}；{风险 3}
```

实测特征：

- 条数 4–6 条，最后两条固定为"投资分析意见"与"风险提示"；
- 每条 120–300 字，**不是一句话提纲**；
- 结论句在句首，且**带一个数字**（如"当前钢铁行业基本面、估值、机构持仓均处于底部区域"虽无数字，但紧随其后 3 条各带一组数字）。

**移植到 REITs 报告**：第一章"投资摘要"采用同一结构，但把"投资分析意见"换成"投资评级与理由"，把"风险提示"换成"最大的风险是……"。

### 规则 2：二级标题 41% 带冒号或破折号，后半句是判断

出处：11 份报告共 200 个形如 `x.y` 的二级标题，其中 82 个含 `：` 或 `,`+判断。

| 类型 | 例 |
|---|---|
| `名词短语：判断` | 「1.3 底部特征：钢企利润情况基本处于历史底部」 |
| `名词短语——判断` | 「1.2 景气回落的原因——地产需求疲弱，但边际影响预期弱化」 |
| `机制：结论` | 「2.1 电煤长协机制变革历史复盘：市场与计划的博弈，基准价抬升」 |
| 纯名词（少数） | 「2.3 长协机制变化对煤炭板块估值的影响」 |

判断依据：前两类合计 82 个，且**几乎全部出现在正文的论证节**；纯名词标题多出现在"行业概况"这类不得不写的背景节。这说明卖方自己也在把"背景节"与"论证节"用标题区分开。

**早期移植记录（已放宽）**：旧版曾要求二级标题论断率 ≥80%。当前 `S-2` 不设论断比例，证据充分时可用判断式标题，法律、结构、背景和测算章节可用准确的描述式标题。

### 规则 3：图表密度 0.80 张/页，即约每 1.25 页一张；每张必写资料来源

出处：327 张 / 408 页。样本内单篇密度区间 0.53（531936）–1.50（532300）。

资料来源写法（原样）：

```
资料来源：国家统计局、钢联数据、申万宏源研究
资料来源：wind，申万宏源研究（EPS 预测均为 wind 一致预期）
```

特征：**来源按"官方数据 → 商业数据库 → 本机构"顺序排列，最后一项固定是研究机构本身**。这条很重要——它明示"这张图的结论是我们加的"，而不是假装数据自带结论。

**早期移植记录（密度配额已取消）**：旧版 `S-6` 曾取每 2,000 字 1 张。当前图表数量服从论证需要，不设固定密度；资料来源和自算属性仍须明确，自算图表注明“本报告整理”或“本报告测算”。

### 规则 4："我们认为"是稀缺词，平均 1.3 次/篇

出处：11 份共 14 次，其中 531887 一篇用了 7 次、6 篇一次没用。

抽样看用法（531887）：

> 「市场普遍将电煤长协视为政策上压低煤价、限制煤企利润弹性的行政工具，因此……；**我们认为**，长协机制的意义不仅是抑制异常波动，更是重塑利润分配方式。」

规律：**只在"市场共识是 A，而本文认为是 B"的转折处出现一次**。它不是口头禅，是立场标记。

**早期移植记录（词频配额已取消）**：旧版 `S-8` 曾限定“我们认为”全文 ≤3 次，用于回应历史报告的空泛重复。当前以表达是否克制、判断是否有证据为准，不以固定词频验收。

| 卖方做法 | 为什么不移植 |
|---|---|
| 一级标题用"主要内容"页列出 4–6 条编号目录 | REITs 单标的报告章节固定（十章），目录由模板保证，不需要在正文重复一遍 |

## 四、统计脚本与可复现性

```bash
# 在 _ref/202608研报_txt 下
python - <<'PY'
import re, glob
for f in sorted(glob.glob('*.txt')):
    t = open(f, encoding='utf-8', errors='ignore').read()
    print(f,
          len(re.findall(r'=== P\d+ ===', t)),   # 页数
          len(re.findall('资料来源', t)),          # 图表数
          len(re.findall('我们认为', t)))
PY
```

二级标题论断率：

```bash
python - <<'PY'
import re, glob
h = [l.strip() for f in glob.glob('*.txt')
     for l in open(f, encoding='utf-8', errors='ignore')
     if re.match(r'^[1-9]\.[0-9]{1,2}\s', l.strip()) and len(l.strip()) < 45]
print(len(h), sum(1 for x in h if '：' in x or ':' in x))
PY
```

## 五、这份统计的边界

1. **样本是行业研究，不是 REITs 研究。** 行业研究的论证对象是"行业景气与估值中枢"，REITs 的论证对象是"单一资产的现金流与期限结构"。骨架可迁移，论证颗粒度不能照搬——行业报告可以只给"预计 2027 年供给收缩 3%"，REITs 报告必须给到"2028 年 2 月 58,306 ㎡ 到期，续租率假设 85%"。
2. **样本只有一家机构。** 中信、中金的 REITs 报告在结构上更偏"资产—租约—估值"三段式，本篇未纳入。因此本 skill 的规则应视为"申万文风的最小公倍数"，不是行业标准。
3. **统计只看结构，不看观点对错。** 327 张图表的论证质量未经审计；本 skill 借用的是它们的**编排方式**，不是它们的结论方法。
