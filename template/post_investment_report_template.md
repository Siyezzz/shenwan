# 投后跟踪报告模板（公募 REITs）

> **用法**：复制本文件到 `outputs/case_XX_<slug>/report_<code>_<period>.md` 后逐节填写。
> 投后报告不追求篇幅，追求**让研究员在十分钟内回答七个问题**：
> ① 这一期是好是坏 ② 哪些资产最好 ③ 哪些在拖累 ④ 收入为什么变 ⑤ 可供分配为什么变 ⑥ 是否可持续 ⑦ 下一季最需关注什么。
> 体例来源：`skills/reits-report-writing/METADATA.md` 的 `outline_schema`（投后 8 节）。
> 硬性下限：**中文正文 ≥3,000 字符**（口径见 `tools/count_report_words.py`）。

---

## 字数与自检约定

- 八节结构固定：结论摘要 / 运营表现 / 区域与项目归因 / 收入与可供分配 / 与预测和契约的对照 / 投资含义 / 风险监测与下一期验证 / 附录
- **数据基础与口径说明不进正文**，全部放附录 A。正文第 1 章必须是结论，不是"我用了什么文件"
- 正文禁用：FLOW 编号、状态码、`bands` 等内部标尺、"本版/初版/修订说明"、"执行 skill"
- 修订记录只写 `run_log.md`，不在正文里交代改了什么
- 每个关键数字后 20 字内给口径 + 期间 + 文件页码

## 3 区域与项目归因

**question**：哪个项目贡献了多少，为什么？

**claim**：

### 3.1 分项目指标

| 项目 | 可租㎡ | 出租率 | 同比 | 租金 | 同比 | 剩余租期 | 归类 |
|---|---|---|---|---|---|---|---|

### 3.2 贡献度分解（可租面积加权）

| 项目 | 权重 | 出租率变动 | 对整体贡献 |
|---|---|---|---|
| 合计 | 100% | | 须与整体变动一致 |

（**归因须闭合**。有残差就必须说明残差从哪来、覆盖多少面积）

### 3.3 原因是资产自身还是区域
（关键判据：**如果所有项目同向变化且都跑赢区域，是区域问题；只有一家变化，是资产问题**。两者的监测指标与持有决策完全不同）

### 3.4 传导到收入

| 项目 | 本期收入 | 上期收入 | 同比 | 占合计 |
|---|---|---|---|---|

（**收入降幅与租金降幅不相等是正常的**，差额来自面积变动与直线法确认。必须解释差额）

**建议字数**：900–1,300

|---|---|---|---|---|---|
| 本季加总 | | | | | |

（**口径差异必须逐项列出并说明以哪个为准**）

### 4.2 可供分配拆解

| 项目 | 金额 | 性质（回加/调增/调减） |
|---|---|---|
| 净利润 | | |
| + 折旧摊销 | | |

| ± 调整项 | | |

（**"调整项占比"必须算**。占比越高，可供分配的"经营纯度"越低）

### 4.3 实际分派 ≠ 可供分配

| 口径 | 金额 | 说明 |
|---|---|---|
| 可供分配 | | |
| 实际分派 | | 含上年结转的须指出 |
| 同口径分派/可供分配 | | 这才是经营口径 |
| 账面分派/可供分配 | | **无经营含义，不可用于判断经营** |

### 4.4 收入与可供分配反向时的机制解释
（三种可能：非现金成本占比上升 / 资本开支与预留减少 / 营运资本释放。**必须指出该机制的"上限"**）

## 6 投资含义

**question**：这些变化对分派能力意味着什么？

**claim**：

### 6.1 分派对租金的敏感度（定量表）

| 情景 | 收入变动 | EBITDA 变动 | 可供分配 | 分派率 |
|---|---|---|---|---|
| 租金持平 | | | | |
| 再降 5% | | | | |
| 再降 10% | | | | |

（**必须写清假设**：传导系数、调整项是否维持不变、分母是否固定。假设登记到附录）

### 6.2 租约期限结构决定下一年的可见度
（剩余租期换算成"未来 12 个月到期占比"。**说明短租期是敏感度放大器，方向取决于租金趋势判断**）

### 6.3 达标为什么不等于投资价值达标
（区分"结果指标"与"输入指标"：通过的是过去的结果，不通过的是未来的输入。**用结果达标覆盖输入恶化是投后分析最常见的逻辑错误**）

### 6.4 对持有人意味着什么
（3 条以内，按重要性排序。每条须可操作——告诉持有人该改什么看法或该盯什么）

**建议字数**：500–800
