**审计对象**：`source_documents/source_index.csv`、`source_documents/` 下全部 PDF、README 与 `outputs/final_acceptance_report.md` 中关于资料数量的表述
**审计时间**：本轮重构期
**审计方式**：脚本逐份读取 PDF（`pypdf`），比对索引字段与实际文件内容；不做抽样，60 份全量
**审计结论**：**索引与文件基本一致，但 README 有两处失实表述必须更正**——① 声称资料"来自上交所公告页"，实际全部来自东方财富公告接口；② 声称"60 份 PDF"与交付声明中"不做分发"并存时，读者会误以为 clone 后可复现，实际 PDF 未入库。

## 2 62 条 ≠ 62 份：索引里有两类记录混在一起

`source_index.csv` 有 62 行，但只有 60 行对应实体文件。另两行是**缺口登记**（gap record），用占位值标记不可得原因：

| case | file 字段 | url 字段 | local_path | status | 含义 |
|---|---|---|---|---|---|
| sinofarm_reit | （资产评估报告原件） | `NOT_DISCLOSED` | 空 | `SOURCE_UNAVAILABLE` | 首农未单独披露资产评估报告原件，招募书内仅有评估结论摘要 |
| huaxia_shen_international | （2024Q1/Q2 季报运营指标表：旧披露格式） | `LEGACY_FORMAT` | 空 | `NOT_COMPARABLE_FORMAT` | 2024 年季报为旧披露格式，指标表结构与 2025 年不同，不解析 |

**这两条记录本身是正确做法**（把"查不到"写进索引，比留空或用估算值填充更诚实），但**不能被计入"共 62 份 PDF"**。此前 README 写"`source_index.csv`（62 条）"与"共 60 份 PDF"并列，读者会以为索引比文件多 2 份未下载的文件——实际是 2 条"确认不可得"的记录。

**统一表述口径**：

> `source_documents/` 下 60 份 PDF，逐份登记于 `source_index.csv`（62 条记录 = 60 条实体 + 2 条缺口登记）。

## 3 来源渠道：不是交易所直连，是东方财富公告接口

**审计发现**：60 条实体记录的 URL **全部**指向 `fund.eastmoney.com/gonggao/`，**没有一条**指向 `www.sse.com.cn` 或 `www.szse.cn`。

而 README 第 71 行原文为：

> 全部案例文件来自上海证券交易所 REITs 公告页（`www.sse.com.cn`）与基金管理人官网披露的原始 PDF

**这是失实表述，必须更正。** 实际路径是：

1. 上交所公告查询接口 `query.sse.com.cn` 需要内部 `channelId`，公开请求不可用（此点在 README 第 47 行已说明）；
2. 因此改用东方财富基金公告接口 `api.fund.eastmoney.com/f10/JJGG`（`type=3` 定期报告分类）枚举并下载；
3. 下载的是**公告原文 PDF**（管理人上传至交易所后由第三方平台转载），文件本身是原始披露件，**但获取渠道是第三方，不是交易所直连**。

**结论**：文件内容可信（原样 PDF、未改写），但**渠道须如实标注**。改后的表述是：

> 全部案例文件通过东方财富基金公告接口（`type=3` 定期报告分类）获取公告原文 PDF，逐份记录 URL 于 `source_index.csv`。上交所公告接口需内部 `channelId`，公开请求不可用，故未走交易所直连。

## 4 能不能说"clone 可复现"：不能

`.gitignore` 明确排除 `source_documents/**/*.pdf`，`git ls-files "source_documents/*.pdf"` 返回 **0**。原因写在 `.gitignore` 注释里：原始披露文件体积大（305MB）且受版权约束，入库等于随仓库分发，与"仅作研究留档、不再分发"的声明冲突。

**因此正确的能力声明是三段，不是一句"可复现"**：

| 能复现的 | 不能复现的 |
|---|---|
| 计算过程（`models/*.py`、`tools/*.py` 可从披露数值重算出全部结论） | 原始 PDF（未入库，需按 `source_index.csv` 的 URL 自行下载） |
| 报告结构（`template/*.md` + `skills/*/FLOW.md`） | 一条命令跑完全流程（下载环节需网络与人工核对） |
| 数值溯源路径（文件 + 页码，41/60 可在正文复核日期，55/60 可在正文复核名称） | — |

**不得声称"clone 后可完全复现"**，只能声称"clone 后可按索引 URL 回溯全部原始披露件，并按 `models/` 与 `tools/` 的脚本重算全部结论"。

### 4.1 `.gitignore` 注释的陈旧数字

`.gitignore` 第 3 行注释写"本地磁盘保留全部 **24 份** PDF"，实际为 60 份。**这是历史遗留（早期只有 24 份时写的），须同步更正**，否则与 README 的 60 份直接矛盾。
