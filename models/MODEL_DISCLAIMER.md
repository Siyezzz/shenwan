# 508601 现金流模型：来源、口径与使用声明

## 1. 模型性质

本工作簿是基于公开披露资料建立的研究测算工具，不是基金管理人、评估机构或审计机构出具的预测、估值或鉴证报告。模型结果是给定输入和假设下的条件计算，不构成收益承诺，也不保证实际经营结果。

“来源可追溯”不等于“来源已独立鉴证”；“公式可复算”不等于“假设必然实现”。任何使用者都应先检查输入来源、指标定义、期间、单位、税务口径和现金流层级。

## 2. 来源优先级

1. 基金合同、招募说明书及其更新稿：产品结构、基金层费用、分配规则和管理人披露预测。
2. 经审计年度报告、定期报告及专项公告：已发生的财务、运营和分派事实。
3. 资产评估报告及其底层预测表：物业层 NOI、评估现金流、折现率、资本化率、收益期限和终值。
4. 租赁合同、租户明细、工程预算和税务资料：租金、免租、租约到期、CAPEX、税费和营运资金驱动。
5. 外部市场数据：仅用于补充市场租金、空置率、可比资产和市场折现率，并记录观察日期及统计口径。
6. 研究假设：仅在可靠披露或可核验数据不足时使用，必须标记为假设并做敏感性分析。

仓库当前的 source_index 将资产评估报告原件标记为未单独取得。因此，本模型不声称已直接复现原评估报告。

## 3. 现金流与指标口径

- 收入：固定租金、提成租金、停车收入、多经收入及其他收入分别核算；总收入必须与披露预测表勾稽。
- EBITDA：沿用招募说明书披露的 EBITDA/“利息、折旧及摊销前利润”口径；不得自动等同 NOI。
- NOI：必须按资产评估报告明确的物业经营收入和经营费用定义计算。本版本没有足够原始资料建立完整 NOI，不以 EBITDA 代替 NOI。
- 可供分配金额：按招募说明书披露的调整项目重建。2026、2027 年纳入披露的营运资金变动和现金调节；2028 年以后营运资金变动暂按 0 占位，属于未验证假设。
- CAPEX：2026、2027 使用披露测算表数值；2028 年以后按收入的 3.5% 情景估算，须以工程预算和维护计划验证。
- 利息及所得税：2028 年以后暂按合计金额每年增长 2% 的研究简化假设；这不是标准会计公式，未来应拆分债务利息与所得税。
- 分派率：本模型展示“可供分配金额/募集规模”的研究口径，不等同实际现金分派收益率。
- IRR：采用年度等间隔现金流，分别展示可供分配金额的 90% 与 100% 作为现金流的两种边界情景。实际投资者回报应按实际买入、除息、支付和退出日期计算 XIRR。
- 终值：当前零终值只是一种压力测试情景，不表示土地或物业在法律到期时实际价值为零。

## 4. 评估增长参数的限制

招募说明书转引的 2.78% 预测期现金流 CAGR 和 2.25% 长期增长率，属于评估现金流参数。没有原评估报告及其现金流定义时，不得将其解释为营业收入增长率。本模型不再把这两个参数用于收入外推；2029 年后的收入增长率作为悲观、中性、乐观研究情景单独输入。

## 5. 估值边界

DCF 的数学形式是将与估值对象相匹配的未来现金流按相匹配的折现率折现。物业层 NOI、项目公司股权现金流、基金层可供分配现金流和投资者现金流不可混用。未取得原始评估报告并完成债务、税费、CAPEX、营运资金、管理费及交易结构桥接前，不得把本模型的基金层现金流现值称为物业评估值、NAV 或合理市值。

## 6. 模型适用限制

- 2028 年到期租约目前采用聚合情景；历史 76.83% 续租率为面积口径，应用于租金收入时仅是代理假设，不是同口径事实。
- 到期租户实际日期不同，目前年度模型将其聚合处理。
- 2028 年以后营运资金变动暂按零处理。
- 利息与所得税尚未拆分。
- CAPEX 3.5% 尚未由工程预算验证。
- 未建立 2045 年部分年度现金流、土地续期成本、处置费用和可回收终值。
- 模型参数存放在 `tools/build_bottomup.py` 和 `tools/build_model.py`。修改情景参数后必须重新生成 CSV 与 Excel，并运行 `tools/validate_model.py` 和仓库回归测试。

## 7. 使用者责任

使用者应核对最新披露、基金合同、法律及税务安排，确认输入数据仍然适用。任何输出均应与其来源、口径、日期和假设一并引用；不得单独摘取某个分派率、现值或 IRR 作为确定性投资结论。
