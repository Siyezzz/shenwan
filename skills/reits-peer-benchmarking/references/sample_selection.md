# 选样：怎么把"类似的项目"变成一份可复现的清单

## 一、为什么"类似"必须先被定义

委托方说"和其他类似的项目比"，这句话里至少有三层歧义，每一层不解决，最后都会变成"我挑了几只我熟悉的"：

| 歧义 | 可能的理解 | 不解决会怎样 |
|---|---|---|
| "类似 ABS 或 REITs" | 公募 REITs / 类 REITs / CMBS / 私募 ABS | 把流动性折价当基本面差异 |
| "类似的项目" | 同资产类型 / 同区域 / 同规模 / 同管理人 | 产业园和高速公路比出租率，指标无意义 |
| "同一时间点" | 年末时点 / 全年期间 / 年报披露日 | 分子分母错配，排名失真 |

## 二、三层收敛（每一层都要写进报告）

### 第一层：产品形态收敛

中国公募 REITs 的交易结构是「公募基金 → 资产支持专项计划 → 项目公司 → 底层物业」，**它在法律形态上就是 ABS 的公开市场版本**。所以境内语境下"类似 ABS 或 REITs"指向同一类产品。

**非公开的类 REITs/CMBS 不纳入**，理由要写清楚：没有公开估值、没有季度运营披露、没有可比市值口径。把三者放进同一张表，得到的"便宜"只是流动性折价。

### 第二层：资产类型收敛

仓储物流、产业园、数据中心、消费基础设施在租约结构、定价机制、资本开支节奏上差异极大：

- 产业园靠政策与产业链，出租率含义不同
- 数据中心靠电力与算力客户，单位是机架不是㎡
- 消费基础设施靠客流，核心指标是销售额提成

**跨类型可以比分派率，不能比资产质量。** 所以样本边界必须锁定在单一资产类型。

### 第三层：可执行条件收敛

落到操作层，五项条件同时满足才纳入：

| 条件 | 判据 | 门槛理由 |
|---|---|---|
| 资产同质 | 同一底层资产类型 | 指标才有意义 |
| 期间完整 | 目标年度为完整 12 个月 | 同比与周转类指标才不失真 |
| 披露可得 | 目标期年报已披露且可下载 | 没有一手数据就没有 A 级证据 |
| 规模下限 | 可租面积 ≥ 10 万㎡（租赁型） | 保证单位化指标有意义 |
| 指标齐备 | 可供分配 + 经营现金流 + 出租率 + 面积 | 缺 blocker 项无法排名 |

## 三、候选池必须全量枚举

```python
# 基金全量清单，约 2 万条
url = "https://fund.eastmoney.com/js/fundcode_search.js"
# 正则不要要求所有字段非空，否则返回 0 条
pat = r'\["(\d{6})","[^"]*","([^"]*)"[^\]]*\]'
# 名称含关键词即入池
kw = ("仓储", "物流")
```

**实测教训**：首版凭印象认为 A 股仓储物流 REIT 只有 4 只，全量枚举后发现是 **10 只**。基于 4 只得出的两条结论在扩到 6 只后被推翻：

- "分派率第一是普洛斯（5.34%）" → 实为中航易商（5.36%）
- "单位面积市值最低是深国际（4,816）" → 实为宝湾（3,871）

**这两个错误的共同点：结论本身算得没错，错在样本。**

## 四、排除理由的三级分类

```
期间不完整  → 可以年化后做边界检验（顺丰 180305，280 天）
披露不可得  → 这一期拿不到，下期可补（安博/菜鸟/中外运）
类型不同质  → 永远不可比（产业园 vs 仓储）
```

三级不能混。把"披露不可得"写成"数据质量差"，会让读者以为文件有问题；把"期间不完整"写成"不可比"，会漏掉一次有价值的边界检验。

## 五、边界检验：四个数回答一个问题

对被排除的标的，只取四个数：

1. 年化分派率（用它自己披露的口径年化）
2. 反推单位面积市值
3. 可租面积
4. 前五集中度

然后回答：**"如果把它拉进来，会改写哪一句结论？"**

### 实测案例：顺丰 180305

| 项目 | 数值 | 纳入后的位置 | 会改写的结论 |
|---|---|---|---|
| 年化分派率 | 约 4.04% | 低于京东 4.05% | **改写"C1 末位是京东"** |
| 单位面积市值 | 约 5,538 元/㎡ | 易商与普洛斯之间 | 普洛斯从第 3 贵变第 4 贵 |
| 可租面积 | 722,329 ㎡ | 第 2 位 | "第二大规模"从 38 万㎡ 变 72 万㎡ |
| 前五集中度 | 约 75% | 中位 | 不改写 |

**结论：纳入它会改写一处细节，不改写三个口径的第一名。**

### 边界检验的诚实边界

年化本身引入假设。仓储物流四季度通常强于前三季度，线性年化可能**低估**顺丰的实际分派率。若季节性调整后高于 4.05%，"顺丰改写 C1 末位"这个结论就不成立。**这层不确定性必须写进报告的"独立假设"附录，不能只写结论。**

## 六、n 很小时的自我约束

| 不做 | 原因 | 替代做法 |
|---|---|---|
| 分位表述（"33 分位"） | 6 个样本算不出有意义的分位数 | 只说"第几名"，且写明是几个样本里的第几名 |
| 显著性检验（p 值） | n=6 无推断能力 | 只报相关系数与残差方向 |
| 加权总分 | 权重取决于投资人偏好 | 给分维度位次 + 条件式优劣 |
| "行业平均" | 6 只的平均不是行业平均 | 说"本组均值"，并列出每只 |

## 七、样本池的下一期维护

样本边界不是一次性的。每期要重跑一遍枚举，检查三件事：

1. 新上市的（顺丰之外还有没有新标的）
2. 补披露的（安博/菜鸟/中外运出了年报就应纳入）
3. 类型漂移的（扩募后资产类型是否还是同质）

**扩样后结论可能变，报告不应预设不变。** 首版 4 只 → 6 只的经验证明：加两只就能推翻两条结论。
