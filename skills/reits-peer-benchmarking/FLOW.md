# FLOW：公募 REITs 横向基准

> 执行顺序 `#1 → #11`。`#5` 之后所有数字只能来自 `panel.csv`，不得回头重读 PDF。
> 标注 `[数据]` 的步骤产出结构化文件；`[非数据]` 的步骤产出判断与文字。

---

```
--{abstract}--
横向比较最容易犯的错，不是算错数，是"选错了比较对象还假装它是全样本"。

一个人手上通常只有三四只熟悉的标的，于是很容易把这三四只当成"同类全部"，
然后在这三四只里排个名，说"我们第一"。这个结论的问题不在计算，在前提：
样本是被记忆选出来的，不是被规则选出来的。

所以第一步不是算指标，是把候选池穷举出来给它看。
穷举之后往往会发现：能比的比想象中少（期间不齐、年报未出、资产不同质），
或者比想象中多（原来还有三只没听说过）。

第二个坑是"一个口径定生死"。分派率的分母有三种（募集规模/评估值/市值），
分子有两种（可供分配/经营现金流），组合起来能给出四个不同的排名。
只说一个，等于在四个答案里挑了一个最好看的。

第三个坑是把"商业模式"写成形容词。好/不好、强/弱，都不算结论。
能算结论的是：钱从哪来、谁在管、风险谁担、增长靠什么——四个问题都有可查的答案。
--
```

## #1 --{定义比较问题，写清"位置"指什么}-- [非数据]

> 参考：`references/output_spec.md` §三（九节骨架，先知道最后要交什么）

先把"相对位置"拆成三个可测的坐标，否则最后一定会写成"综合来看处于中游"这种废话：

1. **收益率位置** —— 在同类里，本项目的现金回报排第几？这个排名换口径还成立吗？
2. **资产质量位置** —— 本项目的资产（出租率、租金趋势、租约、减值）在同类里排第几？
3. **模式位置** —— 本项目的赚钱方式与别人有什么结构性差异？这个差异在什么条件下是优势？

同时写下**不做什么**：不给买入建议、不给目标价、不给总分评级。理由写进正文 §1.3，让读者知道边界在哪。

* 输出：`scope.md`（三个坐标 + 明确的不做清单 + 读者对象）

## #2 --{全量枚举候选池，不用记忆}-- [数据]

> 参考：`references/sample_selection.md` §三（枚举脚本与正则）

**这一步的产出必须是一个清单，不是一个印象。**

- 取基金全量清单：`fund.eastmoney.com/js/fundcode_search.js`（约 2 万条），按名称关键词筛（仓储/物流、产业园、消费、保障房……）。
- 正则不要要求所有字段非空，实测 `\["(\d{6})","[^"]*","([^"]*)"[^\]]*\]` 才稳定命中。
- 逐条登记：代码、全称、成立日、上市日、当前是否有 2025 年报。
- **把候选池规模回报给用户**。如果用户原以为只有 4 只、实际有 10 只，这个差额本身就是结论的一部分。

* 输出：`candidate_pool.csv`（代码 / 简称 / 成立日 / 资产类型 / 是否有目标期年报）
* 自检：候选池只数与用户预期不符时，必须在正文写明"用户预期 N 只，实际 M 只"

## #3 --{过五道筛子，每条排除都要能承受追问}-- [数据]

> 参考：`references/sample_selection.md` §二、§四（三层收敛、排除理由三级分类）

五项条件同时满足才纳入：

| 筛子 | 判据 | 排除后要写什么 |
|---|---|---|
| ① 资产类型同质 | 底层资产为同一类型（如高标准物流仓储，含保税仓） | 写明类型边界，说明跨类型为何不可比 |
| ② 期间完整 | 目标年度为完整 12 个月财年 | 写明成立日与报告期天数 |
| ③ 披露可得 | 目标期年报已披露且可获取 PDF | 写明"披露缺失"而非"数据质量差" |
| ④ 规模下限 | 期末可租面积 ≥ `min_area` | 写明门槛理由：保证单位化指标有意义 |
| ⑤ 指标齐备 | 同时披露可供分配与运营指标 | 缺 blocker 项的，只能进"样本外说明" |

**排除理由分三级，不能混**：`期间不完整`（可以年化后做边界检验）／`披露不可得`（这一期拿不到，下期可补）／`类型不同质`（永远不可比）。三者的处理方式完全不同。

* 输出：`sample_funnel.csv`（代码 / 结论 / 理由 / 可租面积 / 后续动作）
* 自检：每一条"排除"都必须有一句"为什么"，不能只写"不满足条件"

## #4 --{边界检验：把边界动一动，看会改哪一句}-- [数据]

> 参考：`references/sample_selection.md` §五（顺丰 180305 完整实录）

对被排除但可能影响结论的标的（通常是"期间不完整"那一类），只取四个数做检验：

1. 年化分派率（用它自己披露的口径年化，**不要自己二次年化**）
2. 反推单位面积市值
3. 可租面积
4. 前五集中度

然后回答一句：**"如果把它拉进来，会改写哪一句结论？"**

- 改写了 → 在正文点明改哪一句，并说明为什么仍然不纳入（通常是口径不可对齐）
- 没改写 → 说明样本已足够，边界可以不破

**边界可以不破，但必须知道"破了会改哪一句"。** 一句话都改不了的，说明样本饱和。

* 输出：`boundary_test.md`
* 实测：顺丰 180305（280 天）年化 4.04%，恰好低于京东 4.05%——纳入即改写"C1 末位"，但不改写三个口径的第一名

## #5 --{口径对齐，装配唯一数据源}-- [数据]

> 参考：`references/caliber_rules.md` §一—§三、§七（口径四问、五处换算、市值反推、缺口两级）

按 `METADATA.md` 的 `data_requirements` 逐项取数，**每一条都要带 anchor（页码/章节）与 grade（A/B/C/D）**。四类换算必须显式执行：

| 换算 | 公式 | 不换算的后果 |
|---|---|---|
| 租金 天→月 | × 365 ÷ 12 | 差 30 倍，排名全反 |
| 租期 年→天 | × 365 | 差 365 倍 |
| 减值回加 | EBITDA + 资产减值 | 减值大的标的盈利能力被系统性低估 |
| 市值反推 | 可供分配 ÷ 披露分派率 | 用行情市值会造成时点错配 |

**减值回加这一步最能改变结论。** 实测：盐田港未回加时 EBITDA 率 39.2%，回加后 75.56%——从"最差"变"最好"。

* 输出：`panel.csv`（长表：fund / metric / value / unit / caliber / anchor / grade）
* 自检：`grade=C` 的条目必须出现在附录"不可判定"表里，不得在正文当已知数用

## #6 --{三个收益率口径，算排名极差}-- [数据]

> 参考：`references/caliber_rules.md` §四（三处不要碰：分子无唯一正解、结转不是水分、未计提≠未贬值）

三个口径分别回答三个问题，缺一个就会被单一口径误导：

| 口径 | 公式 | 回答 |
|---|---|---|
| C1 披露分派率 | 可供分配 ÷ 市值 | 基金说能分多少 |
| C2 现金分派率 | 经营活动现金流净额 ÷ 市值 | 实际挣了多少 |
| C3 单位面积经营现金流 | 经营活动现金流净额 ÷ 可租面积 | 资产本身能产出多少 |

计算 `排名极差 = max(名次) − min(名次)`：

- 极差 ≤1：可以说"稳定靠前/靠后"
- 极差 ≥2：**任何"排第几"必须带口径标签**，且正文要有斜线图展示翻转
- 全样本极差都 ≥3：说明这个样本里"谁分派率最高"取决于口径，**这本身就是结论**

* 输出：`matrix_yield.csv`（三口径值 + 名次 + 极差）

## #7 --{资产质量四维，集中度单列}-- [数据]

> 参考：`references/caliber_rules.md` §五、§六（集中度口径陷阱、季报与年报冲突）

四个维度各排名次，取**中位数**作为位次（不用排名和，避免极端值主导）：

| 维度 | 方向 | 注意 |
|---|---|---|
| 期末出租率 | 越高越好 | 期末时点，非期间平均 |
| 租金单价同比 | 降幅越小越好 | 基期不足整年时 NA，不插值 |
| 剩余租期 | 越长越好 | **方向随租金周期反转**，必须给剔除版位次 |
| 减值/营业收入 | 越低越好 | 零减值 ≠ 未贬值 |

**租户集中度不并入资产质量**，单列。理由：它衡量"客户是谁"，不衡量"资产好不好"。并入会让"资产优质但客户单一"的标的被错误压低（实测：京东资产质量第 1.5，客户独立性第 6，两个结论同时成立且都有用）。

**集中度必须"口径 + 户数"双标注**，一只标的多套披露全列：

- 面积口径 / 租金口径 / 现金流口径
- 最大一户 / 两户 >10% / 前五
- 关联方与同集团占比（季报常缺，必须回年报 §4.4.2）

* 输出：`matrix_quality.csv`（各维原值 + 名次 + 位次 + 剔除租期的位次）
* 自检：位次在两种算法下变化 ≥1 位的标的，正文必须点明"位次不稳，不宜据此断言优劣"

## #8 --{定价偏离：先算相关，再谈残差}-- [数据]

**禁止用"排序不一致"论证"定价与基本面脱钩"。** 先算三对相关系数：

```
r(市值/㎡, 收入/㎡)   r(市值/㎡, CFO/㎡)   r(收入/㎡, CFO/㎡)
```

- `r > 0.7`：只能做残差分析，不能说"无关/脱钩"
- 残差用 OLS：`CFO/㎡ = a × 市值/㎡ + b`，报告每只的残差率
- 残差 > ±5% 的才是结论对象；其余落在线上，不构成"错价"
- **n < 10 不给 p 值、不说"显著"**，只给方向与幅度

残差的三种解释必须分列，不给单一结论：① 市场错了（需证明信息不对称）② 市场已提前定价未来 ③ 区位本就该折价。

* 输出：正文残差表 + 一张气泡图（市值 vs CFO，含拟合线）
* 实测：六只中四只在 ±4.4% 内，唯二离群的两只恰好是不同方向（−10.9% 与 +13.3%）

## #9 --{商业模式四问，拆到可验证}-- [非数据]

> 参考：`references/business_model.md` 全文（四问、六原型、浮动费、三段式写法）

四个问题，每个都要有可查的答案：

1. **钱从哪来** —— 市场化租金 / 关联协议 / 第三方补足 / 会计调整
2. **谁在管** —— 原始权益人自管还是委托；基础费与浮动费怎么分
3. **风险谁承担** —— 持有人全额承担，还是有兜底（NOI 补足、管理费豁免）
4. **增长靠什么** —— 扩募注入 / 内生提租 / 关联方持续输血

**浮动费/激励费是"谁为结果负责"的合同化证据，必须查执行结果**：负值或零值说明未达标，全额扣减说明条款有牙齿。实测六只里三只触发，方向全部是"未达标"。

**优劣对照表必须写成条件式**：「要现金流稳定性选谁、要票息选谁、要分散选谁」，每行附"适用条件 + 代价 + 验证指标"。**不给总分、不给评级。**

* 输出：正文 §7 六张卡片 + 优劣对照表 + 一张两轴图（赚钱能力 × 分派自给度）

## #10 --{定位与结论：三段式}-- [非数据]

> 参考：`references/output_spec.md` §三、§五（每节必答问题、禁止清单）、`references/few_shots.md`

结论必须落到三句话，每句都带限定：

1. **收益率位置**：排第几 / 换口径后是第几 / 排名极差多少 → 所以这句话能信到什么程度
2. **资产质量位置**：位次多少 / 有无一项进前二 / 剔除争议维度后是否稳定
3. **模式差异**：本项目与对标的结构性差异是什么 / 这个差异在什么条件下是优势

然后是本项目的**可改进处**（每项：现状 → 可改进方向 → 验证指标）与**独特优势**（每项：是什么 → 为什么别人没有 → 什么条件下会消失）。

* 输出：正文 §1 与 §8
* 自检：三句话里出现"综合来看""整体处于中游"这类表述，一律重写

## #11 --{交付与自检}-- [数据]

交付 7 项（md / html / figures / 4 个 csv / 3 个脚本），跑 8 项自检：

| 自检项 | 通过标准 |
|---|---|
| 候选池 | 是全量枚举得出的，不是记忆列的；只数与正文一致 |
| 排除理由 | 每条都有"为什么"，且区分期间/披露/类型三类 |
| 边界检验 | 至少 1 只被排除标的做了"会改哪一句"的检验 |
| 排名极差 | 已计算，且 ≥2 位的标的在正文都带了口径标签 |
| 集中度 | 每只都标了口径与户数；多套披露全列 |
| 商业模式 | 无总分、无评级、无"强/弱"形容词结论 |
| 图表 | 5 张，坐标由脚本计算；HTML 版内联，Markdown 版相对路径 |
| 字数 | 中文正文 ≥15,000 字符（`tools/count_report_words.py`） |

生成顺序：

```
python build_panel.py      # panel.csv / matrix_yield.csv / matrix_quality.csv / sample_funnel.csv
python make_figs.py        # figures/*.svg（坐标由数据计算）
python build_html.py       # 单文件 HTML，SVG 内联
python ../../tools/count_report_words.py report_*.md --min 15000
```

* 输出：md + html + figures + 4 个 csv
