# 公募 REITs 研究报告写作

本 skill 是一个 flow（可执行写作流程），**处在取数层的下游**。

**它解决的是一个问题**：上游研究 FLOW 跑完之后，手上有一堆正确的数字、一个可重算的模型、一张假设表，但写出来的东西读起来像运行日志。原因是**取数流程的骨架（Step 0 → 分层 → 归因 → 测算 → 估值 → 结论）与投研报告的骨架（投资问题 → 论证 → 判断）不是同一个东西**。把 FLOW 的步骤名当章节名，就等于把工序单交给了客户。

**执行方式**：阅读同目录下的 FLOW.md，按 `#1 → #14` 顺序执行。来源、计算、逻辑与表达核验并入 `#10`、`#12` 的现有检查，不要求分轮审稿，不产出独立 review 文件。步骤用于保证证据、测算和表达完整，不把案例模板或形式配额当成跨项目硬规则。

**成稿范式**：投后跟踪报告的版式与句式写在下文《成稿范式：投后跟踪报告》一节——封面八行元信息、`职能短语：本期判断` 式标题、加粗判断句三段式、图表四行式（含差额）、自算与披露不符的四步交代法、跨期表述对照、摘要五段、附录五段、成稿六问。`#4`（定标题）、`#5`（写摘要）、`#7`（标口径）、`#8`（配图表）、`#11`（复核结构）按该节执行；版面几何、配色与字体在 `METADATA.md` 的 `visual_style`，可机检的硬项在 `style_rules` 的 `S-11`—`S-16`。投前与横向基准只借用其中可迁移的部分（标题命名、四步交代法、差额说明、自检六问），不套用投后的章节与附录结构。

**运行前检查**：
1. 核验上游的事实底稿、模型、假设登记、claim 裁决和来源索引，可接受内容等价的底稿。横向基准报告核验 `findings.csv`：每行的判断、用词档位、证据锚点、反例是否齐备。按缺口对判断的影响处理：非核心资料缺失时注明限制并继续可支持的写作；核心证据缺失时先回上游补证，无法补齐则限定受影响结论并标注部分完成。证据边界必须进入正文，不得以文字掩盖缺失，也不因单个文件缺失机械阻断全部写作。
2. 报告里的每一个数字必须能在上游产物里找到，**不允许在写作阶段新造数字**。需要新数字时，退回上游算，不许在正文里"估一个"。
3. 结论先于文字。`#2` 的论点树没定下来之前，不写任何一段正文。
4. **判断的档位也不许改。** 上游标"组内排序"的，正文只能写位次与幅度；要升级用词，退回上游补绝对锚。

**输出位置**：上游约定的 `outputs/{case}/`，文件名沿用既有命名（`report_{code}.md`）。同时产出 `report_metrics.json`（字数、图表数、禁用词命中数），供自动化测试读取。阅读版 `.html` 用 `python tools/render_report.py <report.md>` 生成（图 base64 内嵌、零依赖，几何与配色见 `METADATA.md` 的 `visual_style`），不手写 CSS、不手改 html。

## 这个 skill 回答什么

**不是"怎么把话说完整"，是"怎么让一个没读过原始材料的人，在 15 分钟内看懂这笔资产的处境"。**

两类报告的目标不同：

- **投前分析**：读完要知道——这是什么、赚什么钱、值不值、什么情况下不值；
- **横向基准**：读完要知道——它在同类里是什么位置、这个位置靠什么撑着、哪句话会被下一期数据改写。这类报告**不给买或不买的结论**，所以它的"有用"体现在坐标、幅度与可证伪条件上，不体现在评级上。

两类的共同要求是三条，缺一不算完成：

1. **结论在前，且是判断不是描述。**
2. **每一节回答一个问题。** 标题准确说明本节内容；证据充分时使用判断式标题，法律、交易结构与测算章节可用描述式标题，不为标题强造因果。
3. **正文保留判断所需的证据与计算。** 参数依据、口径差异、关键缺口及其对结论的影响进入正文；流程自检、纠错留痕与完整登记表放入附录。

## 记者视角：你是记者，不是模型

模型的写法是"本报告如何处理这些数据"；记者的写法是"谁在什么时候因为什么多赚或少赚了多少钱"。**读者关心的从来不是你的流程，是那笔钱。**

判断一段是否合格，只问一句：**把这段话念给一个没看过材料的人听，他能不能说出"谁受损、谁受益、大概多少"？** 说不出，这段就是方法论述，删或移到附录。

### 六种必改的写法

| 病 | 反例（模型腔） | 改法（记者腔） | 为什么 |
|---|---|---|---|
| 自指 | 「本报告回答三件事：……」 | 直接给三句判断，不宣告要回答什么 | 报告不是议程，是结论。宣告"我要回答什么"占的是读者最贵的版面 |
| 邀读者核对 | 「读者可以不同意，但能看见怎么选的」「可按 §3.4 逐句核对」 | 「十只仓储 REIT 里四只进不来：三只没有完整年度数据，一只不足十万㎡」 | 把"你可以看"改成"这是事实"。请读者核对，是把责任推回去 |
| 判决交给"本报告" | 「本报告倾向第二种解释」 | 「我们倾向第二种：租金一年跌 17.45%，市场在提前定价继续下跌，不是算错了价」 | 判断要有人承担。全篇只允许"我们"承担三种事：给倾向、承认不知道、承担测算 |
| 形容词结论 | 「资产质量相对较弱」「盈利承压」 | 「出租率 89.54%，比六只中位数低 3.2pct，比第一名低 6.8pct」 | 形容词无法证伪，也无法比较。强弱必须落到数字与对手 |
| 裸数字 | 「计提减值 7,152 万元」 | 「减值 7,152 万元，相当于全年可供分配的 41%」 | 数字要有参照系：占比、相当于、比谁多多少。读者感知不到 7,152 万是什么概念 |
| 清单体 | 「第一，……。第二，……。第三，……」连着三节 | 一段一个因果，先给反常事实，再给解释 | 清单是索引，不是论证。整节都在"第一第二第三"，说明还没想清楚哪句是主句 |

### 三条可以机械执行的编辑动作

1. **换标测试。** 把句子里的标的换成另一只，若句子照样成立，这句没有信息量，删。例：「仓储物流 REIT 普遍面临租金下行压力」→ 换成任何一只都成立，属于背景，不进正文。
2. **删首段。** 每节第一段若在交代背景、定义概念、复述上一节，整段删掉，从第二段开始。第一句应当是这一节最反常的事实。
3. **删尾句。** 每节最后一句若在总结"综上所述""由此可见"，删。读者不需要被告知刚读完什么。

### 允许的例外

口径换算、取数路径、"为什么用反推市值"这类必要说明**不是废话**，但要降级到括号、图注或附录，正文最多留一句"（口径见附录）"。判断标准：删掉这句，结论是否仍成立——成立就移走，不成立才留。

## 三条硬约束

- **正文不出现流程编号与状态码。** `FLOW #n`、`run_log`、`PASS/FAIL`、`CONFIRMED`、`bands 95/90` 一律不得进入正文，只能出现在附录的执行记录或 claim 表里。
- **不写"我做了什么"，只写"事实是什么、意味着什么"。** "本报告的处理是双列并行" → "两个口径都保留：判断收现能力用四季加总，判断全年现金生成用年报数"。
- **不注水。** 字数不够时补的是**论证**（机制、反证、敏感性、可比对照），不是形容词与重复。判据：新增的每一段，删掉之后结论会变弱——如果删掉结论不变，那段是水。

## 成稿范式：投后跟踪报告

`outline_schema.post` 管"写哪几章"，`style_rules` 管"语言什么调性"，本节管**同样的内容怎么排布才读得下去**。它是版式与句式，不是形式配额；某条与具体标的冲突时以内容需要为准，但删掉要能说出理由。

### 封面：一行标题 + 八行元信息

```markdown
# 基金全称（代码）YYYY 年第 N 季度投后跟踪

| 项 | 内容 |
|---|---|
| 基金全称 |  |
| 基金代码 |  |
| 跟踪区间 | 2025Q1–2026Q3，重点期 2025Q4 |
| 重点期截止日 | 2025 年 12 月 31 日 |
| 数据截止日 | 2026 年 10 月 27 日（2026 年第 3 季度报告披露日） |
| 版本 | v1.0 |
| 正文篇幅 | N 个中文字符（第 1—7 章，不含附录与图表） |
| 资料完整性 | 季度报告 N 份、年度报告 N 份、中期报告 N 份、招募说明书 N 版、评估与审计文件 N 份；M 份早期文件无文字层，K 份仅有文本副本，两类均已登记，不参与本期取数 |
```

三条硬要求：

- **`跟踪区间` 与 `重点期` 分两行写。** 序列拉到哪一期（看趋势）和这一期重点分析哪一季（给结论）是两件事。合成一个"分析区间"会让读者以为结论覆盖整个区间。
- **`数据截止日` 带括号说明依据。** 写"2026-10-27"没有信息量，写"2026 年第 3 季度报告披露日"才说明白为什么停在这里。
- **`资料完整性` 不是装饰。** 它要写清两件事：手上有几份、哪几份**不能用**。不能用的必须显式说明原因（无文字层／仅文本副本／未披露），并写明"不参与本期取数"。这一行是全部结论的证据边界声明。

### 章节标题：冒号前给位置，冒号后给本期事实

投后七章不用"运营表现""项目归因"这种工序名。范式是 **`职能短语：本期判断`**：

| 类型 | 例 | 结构 |
|---|---|---|
| 三元并列 | 运营表现：量回升、价下行、期限缩短 | 三个方向各一个动词短语，直接给三维走向 |
| 双主体对撞 | 项目归因：两个园区撑起增幅，三个园区拖累 | 谁贡献、谁拖累，用数量代替形容 |
| 反转 | 收入与可供分配：跌得更快的是分配，不是收入 | 否定读者的默认预期 |
| 转折 | 投资含义：分派还在，但来源在变 | 承认一侧、否定另一侧 |

**自检问句**：把标题里的本期事实换成上一期，句子还成立吗？成立就说明这句是背景、不是判断，重写冒号后的部分。"运营表现：量、价、期限三个维度各往哪走"这类也不合格——它是问题，不是答案，问题属于 `section_contract.question`。

### 正文段落：加粗判断句 + 数字支撑 + 边界

一个自然段内完成三段式：

```
**判断句，≤40 字，句号结尾，含"谁 + 怎么样了"。**
第 2—4 句给数字，每个数字紧跟参照系（占比／相当于／位次／对手比较）。
末句给边界：什么没披露、差从哪来、为什么不可判定。
```

实样：

> **江门鹤山是最大拖累，且原因未披露。** 出租率从 90.02% 降至 64.59%，降 25.43 个百分点，权重 10.71%，单项拖累 −2.722 个百分点（q2025Q4 p13、q2024Q4 p25）。64.59% 是十园最低值，比第二名淀山湖（73.15%）低 8.56 个百分点。季报与年报均未单列退租面积、退租租户或去化计划，这一项的成因不可判定。

判断句必须能单独抽出来当结论用。三种不合格开头：`从运营数据来看……`／`就项目层面而言……`（空转，没说事）；`本季度出租率有所下降`（"有所"是回避幅度）；超过 40 字、带两个以上逗号（判断被稀释）。

**参照系只允许四类**：占比（占收入 82.5%）、相当于（相当于 0.67 个淀山湖）、位次（8 季中位、第 5/8）、对手比较（比第二名低 8.56pct）。四类都写不出来，说明这个数字不该进正文。

### 图：四行式，且必须写差额

```markdown
![图 N 短标题](figures/figN_xxx.png)

图 N 完整标题（含期间与口径）
资料来源：文件简称 页码；招募说明书 YYYY 版 p—p；整理（自算）
口径说明：定义式、取值范围、与披露值的差额及原因
```

关键在第四行。多数报告写到"资料来源"就停，这不够——**口径说明要给出这张图与披露数字差多少、为什么差**：

> 口径说明：贡献 = 面积权重 × 出租率变动；面积权重按 2022-12-31 基准面积计算，合计贡献 +2.981 个百分点，与披露 +3.17 个百分点差 0.19 个百分点。

图内嵌在**它所支撑的那个论证段之后**，不出现"图见附件"或"如图 N 所示"先行指路。短标题（alt）给目录用，完整标题给读者用。

### 表：先结论、后表格、再三行说明

顺序不可颠倒：**论证段 → 表题 → 表格 → 资料来源 → 口径说明**。表题位置按 `figure_table_policy`（在上方），全篇统一，不得一半在上、一半在下。宽表四条：

- 首列是名称列、左对齐；数值列右对齐。
- 差额列用 `+` / `−` 显式带符号，不带符号的"变动（pct）"列会被读成绝对值。
- 缺失值写 `未披露`，不留空、不写 `N/A`、不写 `—`；空单元格会被误认为 0。
- 合计行写 `合计 / 加权`，并让合计值能与披露值并列比较。

### 自算值与披露值不一致：四步交代法

投后报告最容易被抓的地方，是自己算的数和披露的数不一样。范式是**不藏、不取整、不选边**：给自算值 → 给披露值 → 量化差额 → 把差额归到具体口径差异上。

> 按项目可租赁面积加权，2025 年第四季度出租率同比变动可分解为十个园区的贡献之和 +2.981 个百分点，与披露的组合同比 +3.17 个百分点差 0.19 个百分点，差异来自面积口径——分解用招募说明书 2026 版第 270—271 页的 2022 年 12 月 31 日基准面积，合计 1,163,212.20 平方米，与季报期末可供出租面积一致，但个别园区（空港 128,060.52 平方米对季报 128,061.00 平方米）有 0.48 平方米的四舍五入差。

三种不合格处理：只写"基本一致"（不给数就不叫交代）；把自算值改成披露值（分解表行加总与合计行对不上）；两个都写但不解释差（读者会怀疑算术）。差额归不到具体原因时，明写"差额未在披露中定位"，不要编一个口径。

### 跨期表述对照：上年怎么说，一年后怎么样

投后独有、也是最能体现跟踪价值的一种段落，三句结构：引上年同期原文（带页码，逐字或用「」标出）→ 给一年后实际数字 → 判断能否归因（能就归因，不能就写"只能记录方向相反这一事实"）。

> **上年同期对两个园区的表述与一年后的结果方向相反。** 2024 年第四季度季报对江门鹤山的表述为「与新增租户签订长期租约，本期内出租率稳步提升，园区运营稳定性有望逐步增强」；对淀山湖的表述为「累计已完成 133,396.36 平方米替换租户的签约……若后续顺利完成签约，该园区剩余面积有望全部实现去化」。2025 年第四季度实际为江门 64.59%（同比 −25.43 个百分点）、淀山湖 73.15%（同比 −9.25 个百分点）。两处表述均未给出量化去化目标与时间表，因此无法据以判断是执行不力还是市场变化，只能记录方向相反这一事实。

纪律：**陈述、不评价**。不写"管理层失信""承诺落空"，落点放在"表述未含量化目标，因此不可归因"。同一手法用于识别**披露文字与指标读数冲突**：季报正文写"环比保持平稳"、指标是 −2.82 个百分点，就照实并列，并写明"披露文字对短期波动的描述不能替代指标读数"。

### 结论摘要：五段，每段一个判断

不写"本报告分为几部分"，按五个问题各一段：

| 段 | 回答 | 实样首句 |
|---|---|---|
| 1 | 这一季整体是什么 | 2025 年第四季度是量升价跌的一季 |
| 2 | 哪两个数互相矛盾，拆开是什么 | 出租率涨了，收入没跟上 |
| 3 | 分配端怎样，和上期比 | 可供分配金额 8,664.92 万元，同比减 6.62% |
| 4 | 哪个好看的数其实是假象 | 高分派率是当季费用时点配合，不是趋势 |
| 5 | 最该盯哪一项 | 最需要盯的是租期 |

第 4 段是摘要的成败所在：**必须找出一个"看起来好、实际不可持续"的指标并当场拆掉**——高分派率、收缴率破百、出租率反弹都属于这一类。没有这一段，摘要只是把季报又念了一遍。摘要段落不加粗（加粗留给正文），但每段首句就是判断句，只读每段第一句也能得到完整结论。

### 附录：五段

| 段 | 内容 | 形式 |
|---|---|---|
| A.1 口径说明 | 单季与累计、价格口径切换、分派与可供分配的差别、分派率分母 | 两列表：项 / 处理 |
| A.2 数据质量 | 原件互相矛盾、口径断点、四季加总与年报差额 | 五列表：期间 / 指标 / 问题 / 处理 / 标记 |
| A.3 不可判定清单 | 每条给"缺什么 + 因此哪个结论不成立" | 编号列表，每条一句半 |
| A.4 来源索引与图表清单 | 索引表字段说明 + 图清单 + 表清单 | 一段说明 + 两张三列表 |
| A.5 执行记录 | 取数顺序、文件核对结论、面板校验、对账闭合 | 一段散文，用分号连 |

A.2 与 A.3 的分界：**A.2 是"数有问题"，A.3 是"结论做不了"**。四季加总算不出年报数属 A.2；招募书没给当年预测值、导致达成率不可计算属 A.3。A.3 每条必须写清缺口的**后果**，不能只写"未披露"——读者要由此知道这个指标本期作废，而不是"再找找就有"。A.5 只写**做了哪些核对、结果如何**，不写工具名、脚本名、重试过程，它是给复核者的对账线索，不是施工日志。

### 成稿六问

成稿后逐条过，任一条答"否"就回去改：

1. 封面「资料完整性」是否说明了哪几份文件不能用、为什么？
2. 七个章节标题，把本期事实换掉后是否**不再成立**？
3. 每个正文自然段的首句能否单独抽出来当结论？有没有"从……来看"式空转？
4. 每张图、每张表的「口径说明」是否写了与披露值的差额及原因？
5. 全文中"自算值与披露值不一致"的地方，是否都用了四步交代法？
6. 摘要第 4 段是否拆掉了一个"看起来好、实际不可持续"的指标？

各范式小节与 `METADATA.md` 机检项的对应：封面 `S-16`｜标题 `S-11`｜段落三段式 `S-12`｜图四行式与差额 `figure_table_policy`｜四步交代 `S-13`｜跨期表述对照 `S-14`｜摘要第 4 段 `S-15`｜附录五段 `outline_schema.post`。

## 与上游的接口

上游有两类：**取数层**（`reits-pre-investment-analysis`／`reits-post-investment-monitor`）交模型与底稿；**论证层**（`reits-peer-benchmarking`）交判断与档位。前者给数字，后者给结论，接法不同。

| 上游产出 | 本 skill 的用法 | 不得做的事 |
|---|---|---|
| `source_index.csv` + 页码锚点 | 正文数字的原始证据入口；`assumptions.csv` 区分研究假设 | 不把来源索引误当事实表，不在正文里新造数字 |
| `models/cash_flow_model.xlsx` | 情景与敏感性的数来自这里 | 不在正文里手改模型结果 |
| `assumptions.csv` | 每条假设进附录登记表；正文引用时标注"假设" | 不把假设写成"披露" |
| `claims_verdict.csv` | 裁决结果进正文的结论句，`claim_id` 与状态码进附录 | 不在正文里展示 `claim_id` |
| `findings.csv`（横向基准） | 一行一条判断，带**用词档位**（组内排序／相对位置／模型条件下的偏离）；正文按档位写句，不得升格 | 不把"组内排序"档写成"有吸引力"；不合并两条 finding 拼出一个更强结论 |
| `panel.csv` / `matrix_*.csv`（横向基准） | 表格与图的底数，正文数字从此处取 | 不在正文里手算新派生指标 |

**档位是硬约束，不是建议。** 上游标了"组内排序"的句子，正文只能写"组内第 3，与中位差 12bp"；要写成"高于同业"必须上游补出绝对锚。写作层没有权限补，因为这属于判断，不属于表达。

## 学谁的行文

本 skill 的文风规则基于对 11 份卖方行业深度报告的结构统计（共 408 页、327 张图表），是仓库的历史统计记录，不是本次独立复核结果。原始研报未随仓库提交，保留的统计口径和方法记录见研究仓库根目录的 `template/report_style_analysis.md`（不随本 skill 分发）。主要可迁移的四条：

1. **投资摘要先给判断**：概括产品、现金流、估值、主要风险和价格条件，条数按材料复杂度决定。
2. **标题帮助读者定位**：证据充分时可用判断式标题，但法律、结构和测算章节可使用准确的描述式标题。
3. **图表服务于论证并嵌入报告**：按结构、现金流和情景分析需要配置，放在对应论证旁，注明资料来源和自算属性，不设置固定密度。
4. **语言直接克制**：区分事实、预测、假设和判断，避免空泛重复，不以固定词频替代内容审查。

统计口径与原始记录见研究仓库根目录的 `template/report_style_analysis.md`。

**记者腔的参照不是券商深度，是财经报道的调查稿**：主语具体（某座仓库、某个租户、某个条款）、时间具体（哪一年、哪一期）、金额具体（多少、占多少）、判断有署名（谁认为、凭什么）。券商报告可以提供结构与图表规范，但它的"本公司认为""综上所述"不该出现在这里。
