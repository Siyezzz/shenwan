# 公募 REITs 研究报告写作

本 skill 是一个 flow（可执行写作流程），**处在取数层的下游**。

**它解决的是一个问题**：上游研究 FLOW 跑完之后，手上有一堆正确的数字、一个可重算的模型、一张假设表，但写出来的东西读起来像运行日志。原因是**取数流程的骨架（Step 0 → 分层 → 归因 → 测算 → 估值 → 结论）与投研报告的骨架（投资问题 → 论证 → 判断）不是同一个东西**。把 FLOW 的步骤名当章节名，就等于把工序单交给了客户。

**执行方式**：阅读同目录下的 FLOW.md，按 `#1 → #14` 顺序执行。来源、计算、逻辑与表达核验并入 `#10`、`#12` 的现有检查，不要求分轮审稿，不产出独立 review 文件。步骤用于保证证据、测算和表达完整，不把案例模板或形式配额当成跨项目硬规则。

**运行前检查**：
1. 核验上游的事实底稿、模型、假设登记、claim 裁决和来源索引，可接受内容等价的底稿。横向基准报告核验 `findings.csv`：每行的判断、用词档位、证据锚点、反例是否齐备。按缺口对判断的影响处理：非核心资料缺失时注明限制并继续可支持的写作；核心证据缺失时先回上游补证，无法补齐则限定受影响结论并标注部分完成。证据边界必须进入正文，不得以文字掩盖缺失，也不因单个文件缺失机械阻断全部写作。
2. 报告里的每一个数字必须能在上游产物里找到，**不允许在写作阶段新造数字**。需要新数字时，退回上游算，不许在正文里"估一个"。
3. 结论先于文字。`#2` 的论点树没定下来之前，不写任何一段正文。
4. **判断的档位也不许改。** 上游标"组内排序"的，正文只能写位次与幅度；要升级用词，退回上游补绝对锚。

**输出位置**：上游约定的 `outputs/{case}/`，文件名沿用既有命名（`report_{code}.md`）。同时产出 `report_metrics.json`（字数、图表数、禁用词命中数），供自动化测试读取。

## 这个 skill 回答什么

**不是"怎么把话说完整"，是"怎么让一个没读过原始材料的人，在 15 分钟内看懂这笔资产的处境"。**

两类报告的目标不同：

- **投前分析**：读完要知道——这是什么、赚什么钱、值不值、什么情况下不值；
- **横向基准**：读完要知道——它在同类里是什么位置、这个位置靠什么撑着、哪句话会被下一期数据改写。这类报告**不给买或不买的结论**，所以它的"有用"体现在坐标、幅度与可证伪条件上，不体现在评级上。

两类的共同要求是三条，缺一不算完成：

1. **结论在前，且是判断不是描述。**
2. **每一节回答一个问题。** 标题准确说明本节内容；证据充分时使用判断式标题，法律、交易结构与测算章节可用描述式标题，不为标题强造因果。
3. **正文保留判断所需的证据与计算。** 参数依据、口径差异、关键缺口及其对结论的影响进入正文；流程自检、纠错留痕与完整登记表放入附录。

## 记者视角：你是记者，不是模型

模型的写法是"本报告如何处理这些数据"；记者的写法是"谁在什么时候因为什么多赚或少赚了多少钱"。**读者关心的从来不是你的流程，是那笔钱。**

判断一段是否合格，只问一句：**把这段话念给一个没看过材料的人听，他能不能说出"谁受损、谁受益、大概多少"？** 说不出，这段就是方法论述，删或移到附录。

### 六种必改的写法

| 病 | 反例（模型腔） | 改法（记者腔） | 为什么 |
|---|---|---|---|
| 自指 | 「本报告回答三件事：……」 | 直接给三句判断，不宣告要回答什么 | 报告不是议程，是结论。宣告"我要回答什么"占的是读者最贵的版面 |
| 邀读者核对 | 「读者可以不同意，但能看见怎么选的」「可按 §3.4 逐句核对」 | 「十只仓储 REIT 里四只进不来：三只没有完整年度数据，一只不足十万㎡」 | 把"你可以看"改成"这是事实"。请读者核对，是把责任推回去 |
| 判决交给"本报告" | 「本报告倾向第二种解释」 | 「我们倾向第二种：租金一年跌 17.45%，市场在提前定价继续下跌，不是算错了价」 | 判断要有人承担。全篇只允许"我们"承担三种事：给倾向、承认不知道、承担测算 |
| 形容词结论 | 「资产质量相对较弱」「盈利承压」 | 「出租率 89.54%，比六只中位数低 3.2pct，比第一名低 6.8pct」 | 形容词无法证伪，也无法比较。强弱必须落到数字与对手 |
| 裸数字 | 「计提减值 7,152 万元」 | 「减值 7,152 万元，相当于全年可供分配的 41%」 | 数字要有参照系：占比、相当于、比谁多多少。读者感知不到 7,152 万是什么概念 |
| 清单体 | 「第一，……。第二，……。第三，……」连着三节 | 一段一个因果，先给反常事实，再给解释 | 清单是索引，不是论证。整节都在"第一第二第三"，说明还没想清楚哪句是主句 |

### 三条可以机械执行的编辑动作

1. **换标测试。** 把句子里的标的换成另一只，若句子照样成立，这句没有信息量，删。例：「仓储物流 REIT 普遍面临租金下行压力」→ 换成任何一只都成立，属于背景，不进正文。
2. **删首段。** 每节第一段若在交代背景、定义概念、复述上一节，整段删掉，从第二段开始。第一句应当是这一节最反常的事实。
3. **删尾句。** 每节最后一句若在总结"综上所述""由此可见"，删。读者不需要被告知刚读完什么。

### 允许的例外

口径换算、取数路径、"为什么用反推市值"这类必要说明**不是废话**，但要降级到括号、图注或附录，正文最多留一句"（口径见附录）"。判断标准：删掉这句，结论是否仍成立——成立就移走，不成立才留。

## 三条硬约束

- **正文不出现流程编号与状态码。** `FLOW #n`、`run_log`、`PASS/FAIL`、`CONFIRMED`、`bands 95/90` 一律不得进入正文，只能出现在附录的执行记录或 claim 表里。
- **不写"我做了什么"，只写"事实是什么、意味着什么"。** "本报告的处理是双列并行" → "两个口径都保留：判断收现能力用四季加总，判断全年现金生成用年报数"。
- **不注水。** 字数不够时补的是**论证**（机制、反证、敏感性、可比对照），不是形容词与重复。判据：新增的每一段，删掉之后结论会变弱——如果删掉结论不变，那段是水。

## 与上游的接口

上游有两类：**取数层**（`reits-pre-investment-analysis`／`reits-post-investment-monitor`）交模型与底稿；**论证层**（`reits-peer-benchmarking`）交判断与档位。前者给数字，后者给结论，接法不同。

| 上游产出 | 本 skill 的用法 | 不得做的事 |
|---|---|---|
| `source_index.csv` + 页码锚点 | 正文数字的原始证据入口；`assumptions.csv` 区分研究假设 | 不把来源索引误当事实表，不在正文里新造数字 |
| `models/cash_flow_model.xlsx` | 情景与敏感性的数来自这里 | 不在正文里手改模型结果 |
| `assumptions.csv` | 每条假设进附录登记表；正文引用时标注"假设" | 不把假设写成"披露" |
| `claims_verdict.csv` | 裁决结果进正文的结论句，`claim_id` 与状态码进附录 | 不在正文里展示 `claim_id` |
| `findings.csv`（横向基准） | 一行一条判断，带**用词档位**（组内排序／相对位置／确认了位置）；正文按档位写句，不得升格 | 不把"组内排序"档写成"有吸引力"；不合并两条 finding 拼出一个更强结论 |
| `panel.csv` / `matrix_*.csv`（横向基准） | 表格与图的底数，正文数字从此处取 | 不在正文里手算新派生指标 |

**档位是硬约束，不是建议。** 上游标了"组内排序"的句子，正文只能写"组内第 3，与中位差 12bp"；要写成"高于同业"必须上游补出绝对锚。写作层没有权限补，因为这属于判断，不属于表达。

## 学谁的行文

本 skill 的文风规则基于对 11 份卖方行业深度报告的结构统计（共 408 页、327 张图表）。原始研报未随仓库提交，保留的统计口径和方法记录见 `template/report_style_analysis.md`。主要可迁移的四条：

1. **投资摘要先给判断**：概括产品、现金流、估值、主要风险和价格条件，条数按材料复杂度决定。
2. **标题帮助读者定位**：证据充分时可用判断式标题，但法律、结构和测算章节可使用准确的描述式标题。
3. **图表服务于论证**：按结构、现金流和情景分析需要配置，注明资料来源和自算属性，不设置固定密度。
4. **语言直接克制**：区分事实、预测、假设和判断，避免空泛重复，不以固定词频替代内容审查。

统计口径与原始记录见 `template/report_style_analysis.md`。

**记者腔的参照不是券商深度，是财经报道的调查稿**：主语具体（某座仓库、某个租户、某个条款）、时间具体（哪一年、哪一期）、金额具体（多少、占多少）、判断有署名（谁认为、凭什么）。券商报告可以提供结构与图表规范，但它的"本公司认为""综上所述"不该出现在这里。

## report_input_contract

核验上游以下 5 类研究内容，允许由等价底稿承载，不以文件是否单独存在判定能否写作。非核心资料缺失时明确降级并继续可支持部分；核心证据缺失时先补证，无法补齐则限制受影响结论并标注部分完成。缺口、受影响判断和证据边界须进入正文，完整缺口登记留附录，不机械全阻断，也不把资料缺失写成已核验。

| id | 产物 | 必备内容 | 缺失处理 |
|---|---|---|---|
| `IN-1` | 事实底稿 | 关键数字带 `文件 + 页码` 锚点；分 `历史事实 / 文件预测 / 独立假设` 三类 | 无法追溯的事实不得作为确定结论依据；限定受影响判断 |
| `IN-2` | 现金流模型 | 参数与公式分离；可改参数重算；情景覆盖主要风险 | 无法复算的现金流、估值或回报不得报作已验证结果；说明不可测范围 |
| `IN-3` | 假设登记表 | 每条含 `取值 / 依据 / 来源 / 敏感性 / 状态` | 可从等价底稿补登记；无法确认的参数不得混写为披露事实 |
| `IN-4` | claim 裁决表 | 每条含 `aggregation / threshold / observed / verdict / evidence_ref` | 可沿用等价结论证据；缺少支撑的判断降低确定性或保留为不可判定 |
| `IN-5` | 来源索引 | 每条含 `文件名 / 类型 / 日期 / 页数 / URL / 本地路径 / 状态`，不适用项注明 | 可由已有原文锚点补索引；不可回查的关键证据限制相应结论 |

## outline_schema

两套写作层独立骨架，按报告类型选用，不套用取数层 METADATA 的指标 schema。**章节编号是给读者的，不是给流程的**——章节按投资问题组织；影响判断的口径、参数和证据限制须进入相应正文，不以工序名替代分析。下列章节字数区间仅为早期篇幅分配建议，不是上下限或逐章验收配额；投前中文正文合计至少 15,000 字且无上限，投后按任务和论证需要展开。

### 横向基准对比报告（`comparison`）

不回答"值不值得买"，回答"在同类里是什么位置、靠什么撑着、哪句话会被下一期改写"。因此没有评级、没有目标价、没有总分。

| 序 | 章节 | 必须回答的问题 | 写作要点 |
|---|---|---|---|
| 0 | 封面 | 标的代码、比较时点、样本量、版本、字数 | 写清"比较时点"是年报口径，不是行情时点 |
| 1 | 结论与位置 | 这几只各自处在什么位置？一句话说得出来吗 | 三句话：位置、稳定性、结构性来源；附位置表（位次／幅度／锚定三列）。不写"处于中游" |
| 2 | 为什么是这几只 | 样本怎么来的，排除了谁，为什么排除 | 候选池全量枚举 → 逐条排除理由 → 边界检验一只。用户提过 ABS 的，在此交代收敛理由 |
| 3 | 时点、口径与标准 | 拿什么当标准？这些线为什么与样本无关 | 三层参照的取值与阈值、判定用词三档、五处换算。这一节是读者检验全部结论的入口 |
| 4 | 收益率：三个口径 | 换一个口径，名次还成立吗 | 三口径排名 + 排名极差；逐口径过绝对锚（国债溢价）。先写第一名各不相同，再解释为什么 |
| 5 | 资产质量：四个维度 | 这个收益是靠什么换来的 | 四维位次 + 健康线 + 客户结构；给剔除租期的稳健版，说明哪些名次会翻转 |
| 6 | 收益率与质量合起来看 | 贵还是便宜，贵在哪一项 | 定价函数（斜率是一个结论）＋ 残差 ＋ 二维定位。残差三种解释分列，不写买卖信号 |
| 7 | 商业模式：风险在谁的表上 | 谁承担、上限多少、能不能换一张表 | 风险归属表 → 五轴 → 条件式优劣。不给总分，不给"最优模式" |
| 8 | 可改进处与独特优势 | 能改什么、改不动的是什么 | 可改进项四条（挂坐标＋轴＋可迁移性＋下期字段）；优势三条（唯一＋不可复制＋消失条件） |
| 9 | 下一期什么会改写结论 | 到哪一步这句话就不成立了 | 逐句给改写条件（指标＋阈值＋会改写哪一句）。可观测，不写"持续关注" |
| A | 附录 | 来源索引／口径日志／缺口清单／执行记录 | 不计入正文；状态码只允许出现在这里 |

## section_contract

每节写作时逐条自检。**`question` 一栏是这一节的唯一目的**，写不出来就说明这节该删或该并。

| 字段 | 必填 | 说明 |
|---|---|---|
| `section_id` | 是 | 与 `outline_schema` 对应 |
| `question` | 是 | 一句话，必须是疑问句 |
| `claim` | 是 | 本节要证明的判断，一句话 |
| `evidence` | 是 | 支撑该判断的事实、数字或条款，带来源锚点；数量按问题决定 |
| `counter` | 否 | 重要判断的不利证据或替代解释；无充分反证时说明材料限制 |
| `implication` | 是 | 对投资判断的含义，一句话 |
| `min_words` | 否 | 仅作篇幅分配建议，不作为机械失败条件 |
| `figures` | 否 | 本节需要的图表编号 |

## style_rules

| id | 规则 | 判据（可机检） |
|---|---|---|
| `S-1` | 重要分析结论先行；必要的背景、法律及计算说明可按理解顺序展开 | 人工检查，不按首句词形机械失败 |
| `S-2` | 标题清晰：证据充分时可用判断式标题，说明性章节可用准确的描述式标题 | 人工检查 |
| `S-3` | 段落围绕一个问题，长度服从可读性 | 人工检查，非机械失败 |
| `S-4` | 关键数字带口径、期间和来源锚点 | 人工抽查 |
| `S-5` | 历史事实、文件预测和独立假设明确区分 | 表格表头或行标注类型 |
| `S-6` | 图表服务于论证，并注明资料来源和自算属性 | 人工检查 |
| `S-7` | 正文用自然语言表达证据确定性，不展示内部状态码 | 正文不出现状态码 |
| `S-8` | 语言直接克制，避免空泛和重复 | 人工检查 |
| `S-9` | 正文不展开内部运行和修订过程 | 禁用词表 |
| `S-10` | 风险必带传导链：机制 → 证据 → 触发条件 → 财务影响 → 监测指标 | 五要素齐全 |

## voice_rules（记者腔）

判断标准只有一句：**这段话念给没看过材料的人听，他能不能说出"谁受损、谁受益、大概多少"。** 说不出就是方法论述，移附录或删。`V-*` 与 `S-*` 同时适用，冲突时以 `V-*` 为准。

| id | 规则 | 反例 → 改法 | 判据 |
|---|---|---|---|
| `V-1` | 主语是人与钱，不是报告 | 「本报告回答三件事」→ 直接给三句判断 | 正文 0 次「本报告／本文／本篇」作论证主语 |
| `V-2` | 判断有人承担 | 「本报告倾向第二种」→「我们倾向第二种：租金一年跌 17.45%，市场在提前定价继续下跌」 | 「我们」每千字 ≤1 次，且只用于给倾向／承认不知道／承担测算 |
| `V-3` | 数字带参照系 | 「减值 7,152 万元」→「减值 7,152 万元，相当于全年可供分配的 41%」 | 关键数字后 12 字内出现占比、相当于或对手比较之一 |
| `V-4` | 用位次与幅度替代形容词 | 「资产质量相对较弱」→「出租率 89.54%，比中位数低 3.2pct，比第一名低 6.8pct」 | 正文无「显著／明显／较为／整体／一定程度」修饰结论 |
| `V-5` | 一段一个因果，先给反常 | 整节「第一、第二、第三」→ 一段一因，首句给这一节最反常的事实 | 单段出现三个以上并列序号即拆分 |
| `V-6` | 方法降级到括号、图注、附录 | 「本报告用可供分配÷披露分派率反推市值」→「市值按年报反推（口径见附录）」 | 正文方法句删掉后结论仍成立即移走 |
| `V-7` | 不跟读者说话 | 「读者可以不同意」「可按 §3.4 核对」→ 直接陈述事实 | 0 次「读者／可以看到／请注意／综上」 |
| `V-8` | 换标测试 | 「仓储 REIT 普遍面临租金下行压力」→ 换任何一只都成立，属背景，删 | 把标的替换为样本内另一只，句子仍成立即删 |

### editorial_actions（可机械执行）

| id | 动作 | 做法 |
|---|---|---|
| `E-A` | 换标测试 | 把句中标的全换成另一只；仍成立＝无信息量，删 |
| `E-B` | 删首段 | 每节首段若在交代背景、定义概念、复述前文，整段删，从第二段起 |
| `E-C` | 删尾句 | 每节末句若为「综上所述／由此可见／总体而言」，删 |

三条都是**删**，不是改。改出来的句子仍然是原来的结构，删掉之后剩下的才是论证。

## banned_patterns

正文出现任一即判 `FAIL`。附录不受限。

| 类别 | 模式 | 例 |
|---|---|---|
| 流程编号 | `FLOW #\d+`、`§\d+\.\d+（FLOW`、`Step \d` | "资产清单与权属（FLOW #8）" |
| 状态码 | `CONFIRMED`、`PARTIALLY_SUPPORTED`、`INDETERMINATE`、`NOT_COMPARABLE`、`SOURCE_UNAVAILABLE`、`DATA_QUALITY_WARNING`、`UNDEFINED_THRESHOLD` | "估值判断 `PARTIALLY_SUPPORTED`" |
| 测试语 | `PASS`、`FAIL`、`断言`、`自检通过` | "三类型数字是否混列 PASS" |
| 内部标尺 | `bands \d+/\d+`、`阈值档位`、`低位（bands` | "中位（bands 95/90）" |
| 修订语 | `初稿`、`本版`、`上一版`、`修订说明`、`更正清单` | "初稿把 DT51 当作……" |
| 运行语 | `run_log`、`执行 skill`、`按 FLOW 执行`、`产出物` | "执行 skill v1.0.0" |
| 自指语 | `本报告`、`本文`、`本篇`、`本报告组` 作论证主语 | "本报告不预设扩样后结论不变" |
| 读者语 | `读者可以`、`可以看到`、`请注意`、`需要说明的是`、`值得注意的是`、`综上` | "读者可以不同意，但能看见怎么选的" |

自指语与读者语按出现次数判（正文 0 次）；其余元话语不以固定词频判失败。必要的方法说明与证据边界应保留，但按 `V-6` 降级到括号、图注或附录。

## figure_table_policy

| 项 | 规则 |
|---|---|
| 编号 | `表 1`／`图 1`，全文连续，不按章重排 |
| 标题位置 | 表题与图题均在对应图表上方，资料来源置于下方 |
| 资料来源 | 每张必写，格式 `资料来源：{披露文件}、{数据库}、本报告整理` |
| 自算图表 | 资料源须写"本报告整理"，不得伪装成披露数据 |
| 数据表上限 | 无固定行数；按可读性拆分，核心测算不得因行数移出正文 |
| 禁止 | 只罗列字段的"机械表"（如把招募书的产品要素表原样搬入正文）——这类表移附录 |

## word_count_policy

| 项 | 定义 |
|---|---|
| 计数对象 | 中文字符（`[\u4e00-\u9fff]`） |

## versioning_rule

- 报告版本号与 skill 版本号分开记：报告 `v1.0` 起，skill `1.0.0` 起。
- 报告每轮实质修订升 `v0.x`，交付版升 `v1.0`；**版本变更记录只在附录**。
- 文风规则（`voice_rules`）新增或收紧时在附录记一条，说明触发它的反例；可机检项（自指语、读者语、`we` 频次）入 `report_metrics.json`。

- 来源标注可保留必要的"本报告测算"，但每出现一次就问：换成"按 2025 年报重算"是否更具体。可以换的一律换。
[输出]：清晰可读的正文

#10 --{动作}-- [非数据]
**记者腔改写：把"本报告如何处理"改成"谁因为什么多赚少赚"**
- 逐段问一句：念给没看过材料的人听，他能不能说出"谁受损、谁受益、大概多少"。说不出的是方法论述，移附录或删。
- 六种必改：**自指**（"本报告回答三件事"→直接给三句判断）；**邀读者核对**（"读者可以不同意"→直接陈述选样事实）；**判决交给本报告**（"本报告倾向"→"我们倾向"）；**形容词结论**（"质量相对较弱"→位次＋幅度＋与第一名差）；**裸数字**（"减值 7,152 万"→"相当于全年可供分配的 41%"）；**清单体**（整节"第一第二第三"→一段一个因果）。
- 三条机械动作：**换标测试**（把标的换成另一只仍成立＝没有信息量，删）；**删首段**（交代背景、定义概念、复述前文的，整段删）；**删尾句**（"综上所述""由此可见"一律删）。
- 必要的口径说明不算废话，但要降到括号、图注或附录，正文最多留一句"（口径见附录）"。判据：删掉它结论是否仍成立。
- 全篇"我们"只用于三件事：给倾向、承认不知道、承担测算。每千字不超过一次；超出说明在替读者下结论，停下重写。
- 跑一遍 `python tools/check_voice.py <report.md>`：自指语与读者语应清零，裸数字逐条补参照系。工具只报位置不判风格，命中后人工决定删或补。
