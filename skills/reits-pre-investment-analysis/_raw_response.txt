# 公募 REITs 投资分析报告

本 Skill 的最终交付物是**一份能够支持“买、持有、观察或回避”决策的正式投资分析报告**。事实底稿、模型、情景表和测试只是研究证据，不是最终产品。

## 研究问题

回答五个问题：
1. 投资者实际买到什么资产、权利和期限？
2. 底层资产的历史经营质量如何，未来现金流由什么驱动？
3. 管理人/评估机构的预测中，哪些假设可靠，哪些需要调整？
4. 当前发行价或二级市场价格，是否为现金流、期限和风险提供足够补偿？
5. 什么价格和条件下值得买，什么事件会推翻投资逻辑？

## 执行方式

按 `FLOW.md` 的 #1–#26 完成研究。最终报告写作必须衔接 `reits-report-writing`，不可将分析步骤直接拼成章节。

研究顺序：
1. 确认研究基准日、资料截止日、上市状态和投资者视角；
2. 核实材料及口径，形成可追溯事实；
3. 分析交易结构、资产、区域、运营、租约和历史现金流；
4. 先复原披露的可供分配口径，再建立独立预测与情景；
5. 对齐估值对象，计算发行/二级市场价格下的投资者回报；
6. 形成投资评级、合理价格/收益门槛、风险触发条件；
7. 交付正式报告及可复核附件。

## 不可违反的投资研究原则

- **报告结论必须是投资判断**：不能停留在“资产优质”“分派率较高”或复述管理人预测；必须解释价格是否合理、风险是否获得补偿。
- **IPO 与二级市场分开**：发行价认购者与上市后买入者的买入日、价格、分派权利和退出现金流不同，禁止混算。
- **现金流口径分层**：项目公司、专项计划、基金和投资者层级不得混用；NOI、EBITDA、经营现金流、可供分配和实际分派不得互相替代。
- **估值对象一致**：物业价值、项目公司股权价值、专项计划价值、基金份额价值不可直接比较；必须完成债务、税费、管理费、资本开支、营运资本和费用桥接。
- **预测必须由资产驱动**：租约到期、租户集中、租金重定价、空置期、资本开支和税费都要进入预测；历史均值只是参照，不自动等于未来概率。
- **回报必须按投资者现金流计算**：按实际买入、分派权利/支付日期和退出现金流计算 IRR/XIRR。日期或价格缺失时，明确不给精确回报。
- **结论不制造精确性**：缺失材料、未重建模型、口径冲突或不可验证假设必须降低结论确定性，不得用文字包装成确定结论。

## 输入

运行前确认 `METADATA.md` 的基金名称、代码、分析基准日和资料目录。若基金已上市，需取得分析基准日市场价格；若用户要测算特定投资者回报，还需其买入日期、买入价格和分派权利信息。未提供时只能做市场观察或条件分析。

## 最终交付

- 正式投资分析报告（按投资决策逻辑组织，摘要可独立支持初步判断）；
- 事实底稿、来源索引、假设登记、claim 裁决；
- 可重算现金流模型、情景/敏感性结果；
- 报告字数与两轮审稿记录、执行日志。

最终报告必须给出：投资评级、适配投资者/持有期限、合理价格或目标收益条件、关键上行/下行情景、逻辑成立与失效条件。不能计算时要明确说明缺少什么，不能用“建议关注”代替判断。

本流程回答：在给定发行价格和可核验材料下，底层资产现金流能否支持预期分派，发行价格是否补偿了运营、结构、期限和估值风险。顺序是先确认材料与口径，再理解资产和现金流，再独立测算，最后估值并形成投资判断。缺失数据必须说明影响，不得用假设冒充事实。

# Step 2：运营、收入与成本

#11 --{动作}-- [数据]
**还原历史运营表现**
- 按资产和期间列示出租/使用率、租金或收费单价、收缴率、租约期限、租户集中度及业态核心指标。
- 区分期末时点值与期间流量、单季与累计；只有同口径数据才能计算增速。
- 说明数据覆盖率和缺失期间，不用整体均值代替关键项目。
[输出]：历史运营指标表

#12 --{动作}-- [非数据]
**判断运营质量和现金流稳定性**
- 结合出租率与租金变化判断是否以降价换出租；结合租约到期分布、续租记录和租户集中度判断收入稳定性。
- 解释变化来自价格、出租面积、租户结构还是一次性因素，不凭单一指标下结论。出租率上升与租金下降只能先称为同时发生；没有同店/同租户 cohort 或面积结构分解，不得直接断言“降价换量”或将其归因为运营策略。
[输出]：运营质量判断及证据

#13 --{动作}-- [数据]
**拆解历史收入、成本和现金流**
- 按资产/业务拆分租金、服务费、提成收入及主要运营成本、管理费、税费、利息和资本开支。
- 从审计/定期报告勾稽营业收入、利润、经营现金流、EBITDA/NOI（如披露）和可供分配金额，解释会计利润与可分配现金的差异。
- NOI、EBITDA、经营现金流、净利润和可供分配金额不得互相替代。
[输出]：历史经营与现金流桥接表

#14 --{动作}-- [数据]
**建立有依据的经营预测**
- 从单项资产/业务预测面积或业务量、出租/利用率、租金/单价、续租/新增客户、其他收入及运营成本。
- 将现有合同锁定收入与续租、新租、价格增长等未锁定收入分开；按合同到期时间处理空置期、免租期、租金递增和续约假设。
- 重要假设记录取值、依据、期间、来源或研究理由及敏感性。历史均值是参照，不自动等于未来概率或基准值；若基准情景取值高于历史续租率/低于历史 capex，须解释差异。收入公式按资产类型确定，不把单一公式套用于所有 REIT。
[输出]：分资产经营预测与假设表

# Step 3：可供分配与回报

#15 --{动作}-- [数据]
**按披露口径重建可供分配金额**
- 先逐项复原招募书的可供分配金额测算表，明确从净利润/EBITDA/经营现金流到可供分配金额的调整项。
- 识别折旧摊销、利息、税费、资本开支、营运资金、债务偿还、资金沉淀及其他调整的实际处理；只纳入文件支持的项目。
- 不用“收入减成本”或残差反推未披露科目；无法勾稽时保留披露值并标记差异。余额法、经营现金流法和规范化分析口径分列展示，并逐项解释现金、预留、营运资本和一次性资金来源，不能把差额直接归因于募集资金。
[输出]：管理人预测口径的可供分配桥接表

#16 --{动作}-- [数据]
**建立独立现金流模型并对账**
- 用 #14 经营预测及正式文件披露的基金层费用、税费、资本开支和分配调整，独立测算可供分配金额。
- 区分项目公司、专项计划和基金层现金流，按真实结构处理债务、税费和费用，避免重复扣除或漏扣；资本开支至少区分维护性、提升性/扩张性和一次性项目。
- 逐年比较管理人预测与独立模型，解释差异；差异阈值仅作复核提示，不自动代表错误。
- 只设一个权威模型输出。报告、工作簿、情景 CSV 和假设表中的关键年份/情景结果必须逐项对账；不一致时先修正模型或报告，不得同时声称“可复算”。
- 模型输入集中管理、公式可追溯；披露值、外部数据和研究假设分别标识。
[输出]：`models/cash_flow_model.xlsx` 与预测差异表

#17 --{动作}-- [数据]
**计算分派能力与发行价格门槛**
- 单位可供分配金额 = 可供分配金额 ÷ 基金份额；单位分派按基金文件规定的份额口径计算。
- 发行口径收益率 = 预计可供分配金额 ÷ 实际募集规模，并核对发行价格与份额乘积。
- 二级市场买入收益率 = 预计可供分配金额 ÷ 观察日基金市值；同时列示合同分配比例（90%–100%）下的实际现金分派收益率区间。价格、份额、分母必须来自同一观察日。
- 可供分配金额/评估值只能称评估值比率，不称市场分派率。与目标收益率比较前，统一分母、期间和可供分配/实际分派口径。
[输出]：分派测算、价格门槛及口径说明

#18 --{动作}-- [数据]
**做情景与敏感性分析**
- 至少设置悲观、中性、乐观情景；核心驱动来自资产运营证据和合同结构，不直接照搬通用冲击值。没有历史分布或外部证据支持时，情景名称不代表发生概率。
- 对出租/利用率、租金/单价、续租、成本、资本开支、税费和折现率做敏感性；只对相关变量做双因素分析。
- 展示冲击如何传导到可供分配、实际现金分派、分派率和估值，并避免将互相矛盾的假设拼成一个情景。所有情景结果必须来自同一版本的模型。
[输出]：情景表与关键敏感性

# Step 4：估值与投资判断

#19 --{动作}-- [数据]
**复核评估方法与参数**
- 记录评估基准日、评估对象/范围、方法、预测期、收益期限、折现率、增长率、资本化率及终值方法。
- 明确评估对象和价值层级：物业/项目公司资产价值、项目公司股权价值、专项计划价值、基金份额价值不可混称。
- 确认评估现金流口径与独立模型口径一致，再比较参数的市场依据。物业层 NOI/EBITDA 与基金层可供分配现金流不同；只有完成债务、税费、管理费、资本开支、营运资本及交易费用桥接后，才可比较现值，不能把两者差额直接称为估值错配。
- 产权类与特许经营权类分别处理期限和期末价值；终值不得超出权利期限或无依据假设土地续期。
[输出]：评估参数复核表

#20 --{动作}-- [数据]
**形成独立估值区间**
- 使用可验证现金流和匹配的估值方法重估；参数区间须有市场或资产风险依据。
- 分别量化现金流假设和折现率/资本化率变化对估值的影响。
- 建立“物业价值 → 项目公司股权/债务 → 交易对价 → 基金募集规模/份额价值”的桥接表，解释税费、费用、债务、预留及现金余额；不能直接把评估值与募集规模或二级市值视为同一口径。
- 与评估值、交易对价和募集规模比较，注明比较对象及日期；材料不足时缩小结论范围或判为无法判断。
[输出]：独立估值区间与差异解释

#21 --{动作}-- [数据]
**进行可比 REITs 定价比较**
- 选择资产类型、经营模式、期限和风险特征尽量接近的样本，说明筛选理由及不可比之处。
- 统一观察日期、价格和分母口径，再比较分派率、价格/可供分配金额等指标。
- 不强行凑足样本数量；样本不足时说明限制，不将不同业态简单排名。
[输出]：可比估值表

#22 --{动作}-- [数据]
**计算投资者持有期回报**
- 以投资者实际买入日和买入价作为初始负现金流，以其买入后有权取得的每次实际/预测分派及退出净收入为正，按真实日期计算 XIRR。IPO 认购者与二级市场买入者必须分别建现金流，不得把发行价当作上市后买入成本。
- 明确分派记录日/支付日；未确定的日期只能作为假设并做日期敏感性。已在买入日前发生或已除息的分派不得计入该投资者现金流。
- 明确退出价格/估值、交易费用和税费假设，至少给出合理退出情景。缺少可靠支付日期时，不给精确 XIRR，改报期间收益敏感性并标记限制。
- 不得用“累计分派率 + 期末估值变化”冒充 IRR；退出依据不足时单列无终值/清算情景并说明含义。
[输出]：持有期现金流与 IRR 情景表

#23 --{动作}-- [非数据]
**把风险转化为可监测条件**
- 只保留影响投资判断的重大风险，覆盖资产运营、区域市场、交易结构/法律、财务税务、估值与期限。
- 每项说明风险机制、触发条件、监测指标、现金流/估值影响及缓释因素；能量化则用模型测算，不能量化则说明原因。
[输出]：优先级风险表

#24 --{动作}-- [非数据]
**形成可执行的投资判断**
- 回答核心价值、关键风险、决定回报的变量、当前价格隐含预期、合理价值区间、买入价格/目标回报门槛，以及投资逻辑成立和失效条件。
- 明确给出投资评级及其适用投资者、持有期限和前提；评级必须由现金流、估值、安全边际和风险共同推出，不能仅凭分派率高低。
- IPO 与二级市场分别给结论。二级市场买入价上限应由投资者现金流按要求回报率折现推导；若缺少分派日期、退出价值或可验证市场价格，不给伪精确目标价，明确哪些数据补齐后才能计算。
- 区分“资产好不好”与“当前价格值不值得买”。结论须对应估值区间和情景，不得只写“建议关注/谨慎参与”。
[输出]：投资判断、价格条件与失效条件

# Step 5：交付与复核

#25 --{动作}-- [非数据]
