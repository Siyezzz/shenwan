# 公募 REITs 投前分析

本 Skill 不以复述招募说明书为目标，而是回答：**在什么价格和经营假设下，底层资产现金流能够支持预期回报，发行价格是否补偿相应风险？**

## 执行逻辑

按 `FLOW.md` 的 #1–#26 执行：

1. 确认基金、材料版本和证据页码；
2. 理解产品结构、底层资产和运营现金流；
3. 先复原管理人可供分配口径，再建立独立模型并解释差异；
4. 分别按发行价格和二级市场观察价格计算收益率，并按投资者真实买入日期计算持有期回报；
5. 结合估值、风险和价格条件形成投资判断。

## 三条硬约束

- **证据分层**：历史披露、管理人/评估机构预测、独立研究假设必须区分。每项关键事实追溯到具体文件、页码和表格；来源机构名称或仓库索引不等于原始文件。
- **口径一致**：NOI、EBITDA、经营现金流、可供分配金额和实际分派不是同一指标。比较前核对定义、期间、分子和分母；IPO 认购与二级市场买入必须分开建模。
- **不制造精确性**：材料缺失或数据无法勾稽时降低结论确定性；不以行业均值填补标的事实，不用残差命名未披露科目，不用简化收益率冒充 IRR。

## 运行输入

运行前确认 `METADATA.md` 中的 `fund_name`、`doc_root` 和 `analysis_date`。折现率情景、目标收益率和持有期可由用户提供；未提供时使用的默认值必须标为研究假设，不能写成披露事实。

## 交付标准

交付报告、事实底稿、假设登记、现金流模型和运行记录。篇幅服从材料数量和分析复杂度，不以字数替代质量。最终结论说明合理价格/收益条件、关键风险和可观测的逻辑失效条件。

# Step 0：材料与事实底稿

#1 --{动作}-- [数据]
**确认标的与材料**
- 根据基金名称/代码确认标的，并明确**分析基准日、资料截止日和投资决策日**；逐份检查输入目录中的文件是否真实存在、可读取、页数及文字层是否正常。若基准日已晚于基金上市日，必须声明本报告是 IPO 发行定价复盘还是二级市场买入分析，不得混用两者。
- 可参考 `source_documents/source_index.csv` 查找披露文件，但索引/URL 不代表 PDF 已下载。原始 PDF 未随仓库提交；缺失时按 URL 获取，失败则登记，不得声称已阅读。
- 输出 `source_manifest.csv`，记录基金代码、文件名、类型、版本/披露日期、期间、本地路径、来源 URL、存在/可读状态、页数、OCR 状态和选用理由。
[输出]：材料清单与缺失项

#2 --{动作}-- [数据]
**裁决版本并建立证据锚点**
- 按文件类型和用途分别选版本，不能机械套用“封卷稿永远优先”；基准日之后披露的材料单独标为事后信息。
- 招募书/基金合同支持产品和预测，评估报告支持估值参数，法律意见书支持权属合规，审计/定期报告支持历史财务，运营公告支持运营指标。
- 每个关键事实记录具体文件全名、PDF页码（必要时同时记印刷页码）、章节/表格、单位、期间、事实类型和原文定位。市场价格、成交量和可比估值另记观察日期、交易所/数据商及价格口径。来源机构代号、搜索摘要和历史案例不能替代文件证据。
- 不同文件冲突时保留双方数值，解释时点和口径后再裁决；不能解释则标记待核。
[输出]：版本裁决表与字段级证据锚点

#3 --{动作}-- [数据]
**形成统一事实底稿**
- 区分历史披露、管理人/评估机构预测、独立研究假设；统一单位但不混淆单季/累计、时点/期间口径。
- 每项指标记录定义、分子分母、期间属性和来源。缺失区分未披露、不适用、文件缺失、扫描件未识别和来源冲突，并写明影响的模型/结论。
- `dataset/facts.yaml` 是唯一事实底稿；`dataset/facts.csv` 仅为导出视图。
[输出]：事实底稿、标准化数据视图和缺失登记

[输出]：产品概况与发行安排

#5 --{动作}-- [非数据]
**还原交易结构与现金流路径**
- 依据基金合同、招募书和专项计划文件，说明基金、专项计划、项目公司与底层资产的持有/控制关系。
- 画清募集资金支付收购对价的路径，以及经营现金流经税费、债务、专项计划和基金层面到达持有人的路径。
- 只标注文件明确披露的比例、债务和费用；未披露环节标缺失，不推测。
[输出]：结构说明及必要时的结构图

#6 --{动作}-- [非数据]
**核查权属、合同和法律约束**
- 汇总土地/房产权属、用途、期限、抵押查封、许可资质、重大租赁合同、债务及担保。
- 区分法律意见书确认事项、附条件事项和未覆盖事项；法律合规不等于商业价值合理。
[输出]：权属与法律事项清单

#7 --{动作}-- [数据]
**核对收购定价与募集资金用途**
- 勾稽评估值、交易对价、募集规模、发行份额/价格、偿债金额、税费及发行费用。
- 解释评估值至交易对价、交易对价至募集规模的差额和资金用途，识别资金沉淀、额外融资需求及定价溢价。
[输出]：资金用途与定价勾稽表

#8 --{动作}-- [数据]
**建立底层资产清单**
- 按单项资产列示位置、业态、建筑/可租面积、权属、土地/特许经营权期限、评估值及占比。
- 资产组合按项目拆分，不能用组合平均数掩盖单体差异。
[输出]：资产明细表

#9 --{动作}-- [非数据]
**分析区域需求与竞争供给**
- 选取与资产经营半径和业态相关的区域数据：人口/就业/消费或产业需求、同类存量、在建及计划新增供给、租金和空置率。
- 标注数据来源、发布日期和统计范围；招募书中的市场判断属于管理人观点，需外部数据交叉验证。
- 无可靠数据时明确写“无法验证”，不编造区域均值或新增供给。
[输出]：区域市场分析

#10 --{动作}-- [非数据]
**归纳资产竞争力与约束**
- 从区位、资产品质、租户/客户结构、租约、区域供需和权属期限归纳优势与短板。
- 每条判断需有同类参照或历史变化支撑；无参照的只能列为待验证观察。
[输出]：资产优势、短板及其现金流影响

# Step 2：运营、收入与成本

#11 --{动作}-- [数据]
**还原历史运营表现**
- 按资产和期间列示出租/使用率、租金或收费单价、收缴率、租约期限、租户集中度及业态核心指标。
- 区分期末时点值与期间流量、单季与累计；只有同口径数据才能计算增速。
- 说明数据覆盖率和缺失期间，不用整体均值代替关键项目。
[输出]：历史运营指标表

#12 --{动作}-- [非数据]
**判断运营质量和现金流稳定性**
- 结合出租率与租金变化判断是否以降价换出租；结合租约到期分布、续租记录和租户集中度判断收入稳定性。
- 解释变化来自价格、出租面积、租户结构还是一次性因素，不凭单一指标下结论。
[输出]：运营质量判断及证据

#13 --{动作}-- [数据]
**拆解历史收入、成本和现金流**
- 按资产/业务拆分租金、服务费、提成收入及主要运营成本、管理费、税费、利息和资本开支。
- 从审计/定期报告勾稽营业收入、利润、经营现金流、EBITDA/NOI（如披露）和可供分配金额，解释会计利润与可分配现金的差异。
- NOI、EBITDA、经营现金流、净利润和可供分配金额不得互相替代。
[输出]：历史经营与现金流桥接表

#14 --{动作}-- [数据]
**建立有依据的经营预测**
- 从单项资产/业务预测面积或业务量、出租/利用率、租金/单价、续租/新增客户、其他收入及运营成本。
- 将现有合同锁定收入与续租、新租、价格增长等未锁定收入分开；按合同到期时间处理空置期、免租期、租金递增和续约假设。
- 重要假设记录取值、依据、期间、来源或研究理由及敏感性。收入公式按资产类型确定，不把单一公式套用于所有 REIT。
[输出]：分资产经营预测与假设表

# Step 3：可供分配与回报

#15 --{动作}-- [数据]
**按披露口径重建可供分配金额**
- 先逐项复原招募书的可供分配金额测算表，明确从净利润/EBITDA/经营现金流到可供分配金额的调整项。
- 识别折旧摊销、利息、税费、资本开支、营运资金、债务偿还、资金沉淀及其他调整的实际处理；只纳入文件支持的项目。
- 不用“收入减成本”或残差反推未披露科目；无法勾稽时保留披露值并标记差异。余额法、经营现金流法和规范化分析口径分列展示，并逐项解释现金、预留、营运资本和一次性资金来源，不能把差额直接归因于募集资金。
[输出]：管理人预测口径的可供分配桥接表

#16 --{动作}-- [数据]
**建立独立现金流模型并对账**
- 用 #14 经营预测及正式文件披露的基金层费用、税费、资本开支和分配调整，独立测算可供分配金额。
- 区分项目公司、专项计划和基金层现金流，按真实结构处理债务、税费和费用，避免重复扣除或漏扣；资本开支至少区分维护性、提升性/扩张性和一次性项目。
- 逐年比较管理人预测与独立模型，解释差异；差异阈值仅作复核提示，不自动代表错误。
- 只设一个权威模型输出。报告、工作簿、情景 CSV 和假设表中的关键年份/情景结果必须逐项对账；不一致时先修正模型或报告，不得同时声称“可复算”。
- 模型输入集中管理、公式可追溯；披露值、外部数据和研究假设分别标识。
[输出]：`model/cash_flow_model.xlsx` 与预测差异表

#17 --{动作}-- [数据]
**计算分派能力与发行价格门槛**
- 单位可供分配金额 = 可供分配金额 ÷ 基金份额；单位分派按基金文件规定的份额口径计算。
- 发行口径收益率 = 预计可供分配金额 ÷ 实际募集规模，并核对发行价格与份额乘积。
- 二级市场买入收益率 = 预计可供分配金额 ÷ 观察日基金市值；同时列示合同分配比例（90%–100%）下的实际现金分派收益率区间。价格、份额、分母必须来自同一观察日。
- 可供分配金额/评估值只能称评估值比率，不称市场分派率。与目标收益率比较前，统一分母、期间和可供分配/实际分派口径。
[输出]：分派测算、价格门槛及口径说明

#18 --{动作}-- [数据]
**做情景与敏感性分析**
- 至少设置悲观、中性、乐观情景；核心驱动来自资产运营证据和合同结构，不直接照搬通用冲击值。
- 对出租/利用率、租金/单价、续租、成本、资本开支、税费和折现率做敏感性；只对相关变量做双因素分析。
- 展示冲击如何传导到可供分配、分派率和估值，并避免将互相矛盾的假设拼成一个情景。
[输出]：情景表与关键敏感性

# Step 4：估值与投资判断

#19 --{动作}-- [数据]
**复核评估方法与参数**
- 记录评估基准日、评估对象/范围、方法、预测期、收益期限、折现率、增长率、资本化率及终值方法。
- 明确评估对象和价值层级：物业/项目公司资产价值、项目公司股权价值、专项计划价值、基金份额价值不可混称。
- 确认评估现金流口径与独立模型口径一致，再比较参数的市场依据。物业层 NOI/EBITDA 与基金层可供分配现金流不同；只有完成债务、税费、管理费、资本开支、营运资本及交易费用桥接后，才可比较现值，不能把两者差额直接称为估值错配。
- 产权类与特许经营权类分别处理期限和期末价值；终值不得超出权利期限或无依据假设土地续期。
[输出]：评估参数复核表

#20 --{动作}-- [数据]
**形成独立估值区间**
- 使用可验证现金流和匹配的估值方法重估；参数区间须有市场或资产风险依据。
- 分别量化现金流假设和折现率/资本化率变化对估值的影响。
- 建立“物业价值 → 项目公司股权/债务 → 交易对价 → 基金募集规模/份额价值”的桥接表，解释税费、费用、债务、预留及现金余额；不能直接把评估值与募集规模或二级市值视为同一口径。
- 与评估值、交易对价和募集规模比较，注明比较对象及日期；材料不足时缩小结论范围或判为无法判断。
[输出]：独立估值区间与差异解释

#21 --{动作}-- [数据]
**进行可比 REITs 定价比较**
- 选择资产类型、经营模式、期限和风险特征尽量接近的样本，说明筛选理由及不可比之处。
- 统一观察日期、价格和分母口径，再比较分派率、价格/可供分配金额等指标。
- 不强行凑足样本数量；样本不足时说明限制，不将不同业态简单排名。
[输出]：可比估值表

#22 --{动作}-- [数据]
**计算投资者持有期回报**
- 以投资者实际买入日和买入价作为初始负现金流，以其买入后有权取得的每次实际/预测分派及退出净收入为正，按真实日期计算 XIRR。IPO 认购者与二级市场买入者必须分别建现金流，不得把发行价当作上市后买入成本。
- 明确分派记录日/支付日；未确定的日期只能作为假设并做日期敏感性。已在买入日前发生或已除息的分派不得计入该投资者现金流。
- 明确退出价格/估值、交易费用和税费假设，至少给出合理退出情景。缺少可靠支付日期时，不给精确 XIRR，改报期间收益敏感性并标记限制。
- 不得用“累计分派率 + 期末估值变化”冒充 IRR；退出依据不足时单列无终值/清算情景并说明含义。
[输出]：持有期现金流与 IRR 情景表

#23 --{动作}-- [非数据]
**把风险转化为可监测条件**
- 只保留影响投资判断的重大风险，覆盖资产运营、区域市场、交易结构/法律、财务税务、估值与期限。
- 每项说明风险机制、触发条件、监测指标、现金流/估值影响及缓释因素；能量化则用模型测算，不能量化则说明原因。
[输出]：优先级风险表

#24 --{动作}-- [非数据]
**形成有价格条件的投资结论**
- 回答核心价值、关键风险、决定回报的变量、当前价格隐含预期、合理买入价格/收益门槛，以及投资逻辑成立和失效条件。
- 区分“资产好不好”与“发行价格值不值得买”。结论须对应估值区间和情景，不得只写“建议关注/谨慎参与”。
- 关键证据缺失时明确结论限制，不给虚假精确的目标价。
[输出]：投资判断、价格条件与失效条件

# Step 5：交付与复核

#25 --{动作}-- [非数据]
**撰写投前研究报告**
- 按决策逻辑组织：投资结论与价格条件 → 产品/结构 → 资产与区域 → 运营与现金流 → 可供分配与情景 → 估值/回报 → 风险与失效条件。
- 先讲发现，再给证据和推导；避免按资料目录机械复述或重复堆表。篇幅服从分析复杂度，不设凑字数的硬下限。
- 关键数字标注来源页码或模型位置；管理人预测、独立假设和研究判断明确区分。
[输出]：`report_<fund_code>.md`

#26 --{动作}-- [非数据]
**复核并归档**
- 核对材料清单、数字锚点、期间/单位/分母口径、模型公式、情景传导、IRR 现金流和结论一致性。
- 抽查关键数字能否从原文复现；检查是否把预测写成事实、缺失写成零、可供分配写成实际分派。
- 交付：`source_manifest.csv`、`dataset/facts.yaml`、`dataset/facts.csv`、`assumptions.csv`、`model/cash_flow_model.xlsx`、`report_<fund_code>.md`、`run_log.md`。结构图仅在能准确表达交易关系时附上。
- 未完成或证据不足的部分明确标记，不以格式完整代替分析完成。
[输出]：复核记录与交付文件清单
