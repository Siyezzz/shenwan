# 公募 REITs 投资分析报告

本 Skill 的最终交付物是**一份能够支持“买、持有、观察或回避”决策的正式投资分析报告**。事实底稿、模型、情景表和测试只是研究证据，不是最终产品。

## 研究问题

回答五个问题：
1. 投资者实际买到什么资产、权利和期限？
2. 底层资产的历史经营质量如何，未来现金流由什么驱动？
3. 管理人/评估机构的预测中，哪些假设可靠，哪些需要调整？
4. 当前发行价或二级市场价格，是否为现金流、期限和风险提供足够补偿？
5. 什么价格和条件下值得买，什么事件会推翻投资逻辑？

## 执行方式

按 `FLOW.md` 的 #1–#26 完成研究。最终报告写作必须衔接 `reits-report-writing`，不可将分析步骤直接拼成章节。

研究顺序：
1. 确认研究基准日、资料截止日、上市状态和投资者视角；
2. 核实材料及口径，形成可追溯事实；
3. 分析交易结构、资产、区域、运营、租约和历史现金流；
4. 先复原披露的可供分配口径，再建立独立预测与情景；
5. 对齐估值对象，计算发行/二级市场价格下的投资者回报；
6. 形成投资评级、合理价格/收益门槛、风险触发条件；
7. 交付正式报告及可复核附件。

## 不可违反的投资研究原则

- **报告结论必须是投资判断**：不能停留在“资产优质”“分派率较高”或复述管理人预测；必须解释价格是否合理、风险是否获得补偿。
- **IPO 与二级市场分开**：发行价认购者与上市后买入者的买入日、价格、分派权利和退出现金流不同，禁止混算。
- **现金流口径分层**：项目公司、专项计划、基金和投资者层级不得混用；NOI、EBITDA、经营现金流、可供分配和实际分派不得互相替代。
- **估值对象一致**：物业价值、项目公司股权价值、专项计划价值、基金份额价值不可直接比较；必须完成债务、税费、管理费、资本开支、营运资本和费用桥接。
- **预测必须由资产驱动**：租约到期、租户集中、租金重定价、空置期、资本开支和税费都要进入预测；历史均值只是参照，不自动等于未来概率。
- **回报必须按投资者现金流计算**：按实际买入、分派权利/支付日期和退出现金流计算 IRR/XIRR。日期或价格缺失时，明确不给精确回报。
- **结论不制造精确性**：缺失材料、未重建模型、口径冲突或不可验证假设必须降低结论确定性，不得用文字包装成确定结论。

## 输入

运行前确认 `METADATA.md` 的基金名称、代码、分析基准日和资料目录。若基金已上市，需取得分析基准日市场价格；若用户要测算特定投资者回报，还需其买入日期、买入价格和分派权利信息。未提供时只能做市场观察或条件分析。

## 最终交付

- 正式投资分析报告（按投资决策逻辑组织，摘要可独立支持初步判断）；
- 事实底稿、来源索引、假设登记、claim 裁决；
- 可重算现金流模型、情景/敏感性结果；
- 报告字数与两轮审稿记录、执行日志。

最终报告必须给出：投资评级、适配投资者/持有期限、合理价格或目标收益条件、关键上行/下行情景、逻辑成立与失效条件。不能计算时要明确说明缺少什么，不能用“建议关注”代替判断。
