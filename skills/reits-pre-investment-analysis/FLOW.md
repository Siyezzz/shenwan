--{abstract}--
思考路径：
1. 投前分析的材料是多版本、多口径、多主体的。招募说明书有申报稿/反馈稿/封卷稿/更新稿，法律意见书有四版，评估报告可能只有扫描件。不先做版本裁决，后面每个数字都可能取错稿。所以 Step 0 的第一件事不是读内容，是定版本。
2. 交易结构决定现金流路径和税负。基金→专项计划→项目公司→基础设施资产，这条链上每一层的税、费、分配约束都会削减最终可分金额。结构图画不出来，后面的可供分配测算就是空中楼阁。
3. 基础资产的价值来自三件事：位置、租约、期限。位置决定租金天花板，租约决定现金流可预测性，土地剩余年限决定终值。三者缺一，估值结论都要降级。
4. 可供分配金额必须自建模型，不能只抄管理人的预测表。抄表的结果是无法回答"如果出租率降 3 个点会怎样"，而这恰恰是投前最该回答的问题。
5. 估值合理性不靠"评估机构是甲级"来保证，靠参数对比：折现率与同类资产比、资本化率与市场成交比、增长率与租金指数比、终值占比是否过高。四项里有两项无对照，结论只能是 PARTIALLY_SUPPORTED。
6. 最后必须回答：什么价格买合适、什么条件下逻辑失效。不给失效条件的报告，是把风险留给了读者。
--{/abstract}--

#24 --{动作}-- [非数据]
**投资结论与失效条件**
* 信息来源：以上全部
- 必须回答六问：核心投资价值是什么 / 主要风险是什么 / 哪些参数最影响回报 / 哪些风险已被定价 / 哪些未被充分定价 / 什么条件下逻辑成立、什么条件下失效
- 结论必须带价格条件与假设前提，禁止"建议关注"这类无操作含义的表述
- 失效条件写成可观测事件 + 阈值
[输出]：结论段
[输出示例]：
| 问题 | 回答 |
|---|---|
| 核心价值 | 核心区位 + 98% 出租率，分派率 6.7% 高于同业中位 6.1% |

| 逻辑成立 | 发行价对应分派率 ≥6.5% 且 2029 年前完成主力租户续约 |
| 逻辑失效 | 出租率跌破 92% 或续租租金下调超 8% |
