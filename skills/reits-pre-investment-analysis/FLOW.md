--{abstract}--
本流程适用于不同公募 REITs 的投前分析：依据正式披露，判断资产现金流、估值及风险收益是否支持投资。先确认材料与口径，再分析资产并独立测算，最后形成报告。缺失须说明影响，假设不得冒充事实；二级市场分析仅按任务需要开展。
--{/abstract}--

# Step 0：材料与事实底稿

#1 --{动作}-- [数据]
**确认标的、研究任务与投资者视角**
- 确认基金名称/代码、分析基准日、资料截止日和研究任务；默认按所给披露分析项目及发行投资价值，不因已上市自动切换二级市场。
- 仅在任务需要时取得观察日价格及假设买入日期；参考价不得冒充实际成交价，发行价不得当作上市后买入成本。价格无法核实时给条件判断。
- 先查仓库已有数据、案例底稿和来源索引，再核验对应原始文件的存在、可读性、页数及文字层；旧案例仅作参考，不直接沿用结论。
- 可参考 `source_documents/source_index.csv` 查找披露文件，但索引/URL 不代表 PDF 已下载。原始 PDF 未随仓库提交；缺失时按 URL 获取，失败则登记，不得声称已阅读。
- 更新 `outputs/{case_dir}/source_index.csv`，保留既有字段，并核对本地路径、存在/可读状态、页数、OCR 状态和选用理由；根目录 `source_documents/source_index.csv` 是跨案例发现索引，不作为案例运行产物重复覆盖。
[输出]：材料清单与缺失项

#2 --{动作}-- [数据]
**裁决版本并建立证据锚点**
- 按文件类型和用途分别选版本，不能机械套用“封卷稿永远优先”；基准日之后披露的材料单独标为事后信息。
- 招募书/基金合同支持产品和预测，评估报告支持估值参数，法律意见书支持权属合规，审计/定期报告支持历史财务，运营公告支持运营指标。
- 每个关键事实记录具体文件全名、PDF页码（必要时同时记印刷页码）、章节/表格、单位、期间、事实类型和原文定位。市场价格、成交量和可比估值另记观察日期、交易所/数据商及价格口径。来源机构代号、搜索摘要和历史案例不能替代文件证据。
- 不同文件冲突时保留双方数值，解释时点和口径后再裁决；不能解释则标记待核。
[输出]：版本裁决表与字段级证据锚点

#3 --{动作}-- [数据]
**形成统一事实底稿**
- 区分历史披露、管理人/评估机构预测、独立研究假设；统一单位但不混淆单季/累计、时点/期间口径。
- 每项指标记录定义、分子分母、期间属性和来源。缺失区分未披露、不适用、文件缺失、扫描件未识别和来源冲突，并写明影响的模型/结论。
- 本流程以案例目录的 `source_index.csv` 作为来源索引、`assumptions.csv` 作为研究假设底稿、`claims_verdict.csv` 作为结论证据裁决；事实数值必须保留具体文件、页码和表格锚点，并在模型输入中标明来源。
[输出]：案例来源索引、假设登记、关键事实与证据锚点

# Step 1：产品、结构与资产

#4 --{动作}-- [非数据]
**说明产品和发行安排**
- 列明基金类型、期限、管理人/托管人、发行份额与价格、募集规模、战略配售/原始权益人持有安排及募集资金用途。
- 区分产权类与特许经营权类，说明期限届满时资产或经营权的处理，不得笼统假设期末价值归零或存在残值。
[输出]：产品概况与发行安排

#5 --{动作}-- [非数据]
**还原交易结构与现金流路径**
- 依据基金合同、招募书和专项计划文件，说明基金、专项计划、项目公司与底层资产的持有/控制关系。
- 画清募集资金支付收购对价的路径，以及经营现金流经税费、债务、专项计划和基金层面到达持有人的路径。
- 只标注文件明确披露的比例、债务和费用；未披露环节标缺失，不推测。
[输出]：结构说明及必要时的结构图

#6 --{动作}-- [非数据]
**核查权属、合同和法律约束**
- 汇总土地/房产权属、用途、期限、抵押查封、许可资质、重大租赁合同、债务及担保。
- 区分法律意见书确认事项、附条件事项和未覆盖事项；法律合规不等于商业价值合理。
[输出]：权属与法律事项清单

#7 --{动作}-- [数据]
**核对收购定价与募集资金用途**
- 勾稽评估值、交易对价、募集规模、发行份额/价格、偿债金额、税费及发行费用。
- 解释评估值至交易对价、交易对价至募集规模的差额和资金用途，识别资金沉淀、额外融资需求及定价溢价。
[输出]：资金用途与定价勾稽表

#8 --{动作}-- [数据]
**建立底层资产清单**
- 按单项资产列示位置、业态、建筑/可租面积、权属、土地/特许经营权期限、评估值及占比。
- 资产组合按项目拆分，不能用组合平均数掩盖单体差异。
[输出]：资产明细表

#9 --{动作}-- [非数据]
**分析区域需求与竞争供给**
- 选取与资产经营半径和业态相关的区域数据：人口/就业/消费或产业需求、同类存量、在建及计划新增供给、租金和空置率。
- 标注来源、发布日期和统计范围；招募书的市场观点与独立验证分开，外部数据仅在检验关键假设需要时补充。
- 无可靠数据时明确写“无法验证”，不编造区域均值或新增供给。
[输出]：区域市场分析

#10 --{动作}-- [非数据]
**归纳资产竞争力与约束**
- 从区位、资产品质、租户/客户结构、租约、区域供需和权属期限归纳优势与短板。
- 每条判断需有同类参照或历史变化支撑；无参照的只能列为待验证观察。
[输出]：资产优势、短板及其现金流影响

# Step 2：运营、收入与成本

#11 --{动作}-- [数据]
**还原历史运营表现**
- 按资产和期间列示出租/使用率、租金或收费单价、收缴率、租约期限、租户集中度及业态核心指标。
- 区分期末时点值与期间流量、单季与累计；只有同口径数据才能计算增速。
- 说明数据覆盖率和缺失期间，不用整体均值代替关键项目。
[输出]：历史运营指标表

#12 --{动作}-- [非数据]
**判断运营质量和现金流稳定性**
- 结合出租率与租金变化判断是否以降价换出租；结合租约到期分布、续租记录和租户集中度判断收入稳定性。
- 解释变化来自价格、出租面积、租户结构还是一次性因素，不凭单一指标下结论。出租率上升与租金下降只能先称为同时发生；没有同店/同租户 cohort 或面积结构分解，不得直接断言“降价换量”或将其归因为运营策略。
[输出]：运营质量判断及证据

#13 --{动作}-- [数据]
**拆解历史收入、成本和现金流**
- 按资产/业务拆分租金、服务费、提成收入及主要运营成本、管理费、税费、利息和资本开支。
- 从审计/定期报告勾稽营业收入、利润、经营现金流、EBITDA/NOI（如披露）和可供分配金额，解释会计利润与可分配现金的差异。
- NOI、EBITDA、经营现金流、净利润和可供分配金额不得互相替代。
[输出]：历史经营与现金流桥接表

#14 --{动作}-- [数据]
**建立有依据的经营预测**
- 从单项资产/业务预测面积或业务量、出租/利用率、租金/单价、续租/新增客户、其他收入及运营成本。
- 将现有合同锁定收入与续租、新租、价格增长等未锁定收入分开；按合同到期时间处理空置期、免租期、租金递增和续约假设。
- 重要参数并列披露值与独立取值，说明合同/历史依据、设定合理性及结果影响；偏离历史水平须解释。历史均值不等于未来概率，收入公式按资产类型确定。
[输出]：分资产经营预测与假设表

# Step 3：可供分配与回报

#15 --{动作}-- [数据]
**按披露口径重建可供分配金额**
- 先逐项复原招募书的可供分配金额测算表，明确从净利润/EBITDA/经营现金流到可供分配金额的调整项。
- 识别折旧摊销、利息、税费、资本开支、营运资金、债务偿还、资金沉淀及其他调整的实际处理；只纳入文件支持的项目。
- 不用“收入减成本”或残差反推未披露科目；无法勾稽时保留披露值并标记差异。余额法、经营现金流法和规范化分析口径分列展示，并逐项解释现金、预留、营运资本和一次性资金来源，不能把差额直接归因于募集资金。
[输出]：管理人预测口径的可供分配桥接表

#16 --{动作}-- [数据]
**建立独立现金流模型并对账**
- 用 #14 经营预测及正式文件披露的基金层费用、税费、资本开支和分配调整，独立测算可供分配金额。
- 区分项目公司、专项计划和基金层现金流，按真实结构处理债务、税费和费用，避免重复扣除或漏扣；资本开支至少区分维护性、提升性/扩张性和一次性项目。
- 逐年比较管理人预测与独立模型，解释差异；差异阈值仅作复核提示，不自动代表错误。
- 只设一个权威模型输出。报告、工作簿、情景 CSV 和假设表中的关键年份/情景结果必须逐项对账；不一致时先修正模型或报告，不得同时声称“可复算”。
- 模型输入集中管理、公式可追溯；披露值、外部数据和研究假设分别标识。
[输出]：`models/cash_flow_model.xlsx` 与预测差异表

#17 --{动作}-- [数据]
**计算分派能力与发行价格门槛**
- 单位可供分配金额 = 可供分配金额 ÷ 基金份额；单位分派按基金文件规定的份额口径计算。
- 发行口径收益率 = 预计可供分配金额 ÷ 实际募集规模，并核对发行价格与份额乘积。
- 任务涉及二级市场时，以观察日市值计算可供分配收益率；实际分派按合同分配规则和预留假设另算。价格、份额和分母须同日同口径。
- 可供分配金额/评估值只能称评估值比率，不称市场分派率。与目标收益率比较前，统一分母、期间和可供分配/实际分派口径。
[输出]：分派测算、价格门槛及口径说明

#18 --{动作}-- [数据]
**做情景与敏感性分析**
- 至少设置悲观、中性、乐观情景；核心驱动来自资产运营证据和合同结构，不直接照搬通用冲击值。没有历史分布或外部证据支持时，情景名称不代表发生概率。
- 对出租/利用率、租金/单价、续租、成本、资本开支、税费和折现率做敏感性；只对相关变量做双因素分析。
- 同表比较各情景的可供分配、现金分派、估值、总回报（可计算时）与风险触发条件；假设须相容，结果来自同一模型版本。
[输出]：情景表与关键敏感性

# Step 4：估值与投资判断

#19 --{动作}-- [数据]
**复核评估方法与参数**
- 记录评估基准日、评估对象/范围、方法、预测期、收益期限、折现率、增长率、资本化率及终值方法。
- 明确评估对象和价值层级：物业/项目公司资产价值、项目公司股权价值、专项计划价值、基金份额价值不可混称。
- 确认评估现金流口径与独立模型口径一致，再比较参数的市场依据。物业层 NOI/EBITDA 与基金层可供分配现金流不同；只有完成债务、税费、管理费、资本开支、营运资本及交易费用桥接后，才可比较现值，不能把两者差额直接称为估值错配。
- 产权类与特许经营权类分别处理期限和期末价值；终值不得超出权利期限或无依据假设土地续期。
[输出]：评估参数复核表

#20 --{动作}-- [数据]
**形成独立估值区间**
- 使用可验证现金流和匹配的估值方法重估；参数区间须有市场或资产风险依据。
- 分别量化现金流假设和折现率/资本化率变化对估值的影响。
- 建立“物业价值 → 项目公司股权/债务 → 交易对价 → 基金募集规模/份额价值”的桥接表，解释税费、费用、债务、预留及现金余额；不能直接把评估值与募集规模或二级市值视为同一口径。
- 与评估值、交易对价和募集规模比较，注明比较对象及日期；材料不足时缩小结论范围或判为无法判断。
[输出]：独立估值区间与差异解释

#21 --{动作}-- [数据]
**按需进行可比 REITs 定价比较**
- 选择资产类型、经营模式、期限和风险特征尽量接近的样本，说明筛选理由及不可比之处。
- 统一观察日期、价格和分母口径，再比较分派率、价格/可供分配金额等指标。
- 仅在能支持参数或定价判断时开展；不凑样本、不跨业态简单排名，数据不足时说明限制。
[输出]：可比估值表

#22 --{动作}-- [数据]
**计算投资者持有期回报**
- 按研究任务设定认购/买入、分派及退出现金流，说明价格、期限、费用与退出依据；不同投资者视角分开，持有期不固定为三年。
- 等间隔预测用 IRR，日期可核验时用 XIRR；未确定日期标为假设，不强求历史支付记录。已除息或买入前分派不得计入。
- 日期、退出或价格依据不足时给条件区间并说明限制；不得以累计分派率加估值变化冒充 IRR，也不得无依据设终值或清算价值。
[输出]：持有期现金流与 IRR 情景表

#23 --{动作}-- [非数据]
**把风险转化为可监测条件**
- 只保留影响投资判断的重大风险，覆盖资产运营、区域市场、交易结构/法律、财务税务、估值与期限。
- 每项说明风险机制、触发条件、监测指标、现金流/估值影响及缓释因素；能量化则用模型测算，不能量化则说明原因。
[输出]：优先级风险表

#24 --{动作}-- [非数据]
**形成可执行的投资判断**
- 回答核心价值、关键风险、决定回报的变量、当前价格隐含预期、合理价值区间、买入价格/目标回报门槛，以及投资逻辑成立和失效条件。
- 明确给出投资评级及其适用投资者、持有期限和前提；评级必须由现金流、估值、安全边际和风险共同推出，不能仅凭分派率高低。
- 只对任务选定的发行/二级市场视角下结论；价格门槛由投资者现金流及要求回报率推导。缺少价格、期限或退出依据时给条件判断，不给伪精确目标价。
- 区分“资产好不好”与“当前价格值不值得买”。结论须对应估值区间和情景，不得只写“建议关注/谨慎参与”。
[输出]：投资判断、价格条件与失效条件

# Step 5：交付与复核

#25 --{动作}-- [非数据]
**生成正式投资分析报告**
- 本 Skill 的最终产品是投资分析报告，不是模型文件或数据表。研究分析完成后，必须调用/遵循 `reits-report-writing` 的写作流程，将论点树、投资判断和证据组织成可供投资决策的正式报告；不得把 #1–#24 的步骤名称直接当作章节目录。
- 报告正文按决策逻辑组织：投资结论与价格条件 → 产品/交易结构 → 资产与区域 → 运营与租约 → 历史财务 → 未来现金流 → 估值与定价 → 分派与投资者回报 → 风险 → 评级与行动条件。
- 摘要必须自足，明确产品买的是什么、现金流靠什么、主要分歧、估值/价格条件、预期回报边界、最大风险和评级。每章先给判断，再给证据、机制、反证和投资含义。
- 关键数字标注原始文件页码或模型位置；管理人预测、独立假设和研究判断明确区分。不得在写作阶段新造数字；需新增测算时退回模型步骤。
- 正文至少 1.5 万字，无上限；按写作 Skill 的正文统计口径验收，不以附录注水。参数合理性、计算过程和风险收益比较须在正文。
[输出]：`outputs/{case_dir}/thesis.md`、`report_<fund_code>.md`、`report_metrics.json`
#26 --{动作}-- [非数据]
