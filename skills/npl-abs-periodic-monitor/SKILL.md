# 不良 ABS 存续期定期监测

将存续期披露整理为“实际回收 → 原始预测对照 → 资金分配与证券余额 → 剩余资产质量”的可复核流程。阅读 [FLOW.md](FLOW.md)，按 #1—#12 执行；字段、公式及验收规则以 [METADATA.md](METADATA.md) 为准，写作衔接阅读 [references/report-handoff.md](references/report-handoff.md)。

运行前锁定附件路径、请求标的、截止范围和授权模式。用户只要求编写或修改技能时，仅编辑技能定义，不读取案例正文、不抽取真实指标、不生成案例底稿或报告。执行监测时默认止于底稿与 handoff；只有用户明确要求写报告后才进入写作层。

## 证据与身份门槛

仅将运行时 `evidence_scope` 登记、用户授权的附件成员作为金融事实证据；`archive_path`、`doc_root`、预期报告清单及截止范围按项目配置，不设产品、路径或期数默认值。参考仓库只提供技能与文风格式，不能成为金融论据，不联网补金融资料。新增附件须由用户明确扩展证据边界后再登记。建鑫验收配置集中在 [references/report-handoff.md](references/report-handoff.md) 的案例区，仅在任务明确指定该案例时使用。

保留 `requested_identity` 与 `verified_identity`。文件名中的全称、代码或档次与请求不一致时登记待核冲突，不能直接判定代码对应档次。核对发行说明书证券分层、发行结果与受托报告正文中的全称、代码、档次及初始余额；未解冲突只允许资产池层面独立可核数据，不得跨档加总、拼接本息、余额、兑付率或安全性结论。

执行时必须重新枚举授权附件、核页、抽取并对关键数字原页复核；候选文档清单与份数只是待核线索，不视为正文核验。PDF 工具不可用、无文字层或 OCR 未核实，登记对应不可读状态，禁止凭文件名或模型记忆填值。

## 必须保留的分析边界

- 报告序号不等于自然半年。分别核对归集期、报告覆盖期、分配/支付日、时点余额及累计起点；首期、过渡期等短区间不得硬套完整半年。无法精确拆分自然半年时保留原区间，不按天或线性分配现金。
- 同一资产边界、期间起点、毛净口径和单位才允许差分。分期实际与预计、累计实际与预计在同表并列；累计差额由同范围累计数相减，不再累加历期累计值。
- 分开回收本金、回收利息及其他款、本息回收、毛/净回收、处置笔数、处置债权本金、减记本金；费用、税费、回款划转、储备、待付款与证券分配各有层级，不能互相替代。
- 原始发行预测、修订预测、评级情景与契约义务分别登记。评级预测不能替代发行基准；只有年度或终值预测时保留共同可比区间，不造半年预测。
- 实付不等于应付；建立现金桥与逐档证券本金桥，保留残差及原因状态，不以“其他”强行填平。未核实应付利息不得仅凭实付推断足额兑息。
- 用同区间指标描述稳定性，日均值只作观察辅助，不能推成线性回收预测；剩余池质量变化须考虑较易处置资产先退出的选择效应。司法、房价或服务机构执行原因只在附件有证据时确认；推断、未披露与披露事实分列。

## 上下游分工与交付

本技能从授权附件独立完成存续期研究、计算与判断，无须先运行 `mortgage-npl-abs-protection`。已有同一附件、同一身份和基准日的已核验上游底稿时可选择复用并复核引用链；新增发行资产九维度或临界回收测算属于另行研究范围，按任务需要再转接，不阻断本技能独立结论，不把历史临界回收阈值当成当前契约。

向现有 `reits-report-writing` 主入口交接标准底稿及 `report_handoff`。用户要求成稿时，由写作技能独立组织一篇完整的 ABS 存续期报告，研究底稿与交接包不能替代成稿。仅迁移结论先行、证据引用、图表内嵌和语言规则，不套 REIT 七章、运营指标或强制反转；写作层只能使用已验证原值及可复算派生值，不新增数字或提升判断强度。

与保护技能共享信托级case_id、文件SHA256 source_id、比例0—1和findings.kind的fact/calculation/judgment三层；推断以判断子类型记录，逐值证据定位与详细状态按METADATA保留。跨技能交接先核对身份、期间和口径，不重复转换比例。

本技能定义 `source_index、panel、period_map、forecast_baseline、period_comparison、cash_reconciliation、security_bridge、claims_verdict、findings、assumptions、gaps、report_handoff` 十二类底稿。未捆绑执行脚本；不得声称运行了不存在的校验脚本或已分析过示例案例。按 METADATA 的验收规则逐项复算，记录实际使用工具和未完成项。
