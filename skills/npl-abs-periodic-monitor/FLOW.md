--{abstract}--
先核对证券身份、证据完整性与真实区间，再统一观测口径。以发行说明书可回查的原始预测作为基准，逐期并列实际与预计、累计及偏差，分别核对资产现金与证券偿付，最后讨论剩余资产质量及未来可验证事项。所有判断都从标准底稿派生，不凭报告日期拼半年，不把已实付当作应付已足额，不把预测偏差当作违约。缺口只阻断依赖它的结论，保留独立成立的研究。用户只要求技能时不执行本流程；监测运行默认止于交接。
--{/abstract}--

# Step 0：封闭证据与身份

#1 --{动作}-- [非数据]
**锁定任务模式、来源与请求身份**
* 数据依赖：用户指令、运行时evidence_scope、METADATA inputs
- 区分 `skill_only / monitor / monitor_and_report`；`skill_only` 立即停止案例执行，仅修改技能。
- 锁定附件清单及哈希/文件版本、解压目录、请求代码和名称、截止范围。不得读取外部金融资料或把格式参考当证据。
- 在运行参数记录 requested_identity；尚无正文证据时 verified_identity 保持空并登记 `IDENTITY_UNRESOLVED`。
[输出]：运行边界与 assumptions/gaps 的模式记录。
[输出示例]：`mode=monitor；requested_identity=用户请求原文；verified_identity=待正文核验`（字段示意，非案例事实）。

#2 --{动作}-- [数据]
**枚举附件并验证档次身份及可读性**
* 数据依赖：附件内全部 PDF；发行说明书、发行结果、受托报告的身份页
- 依据运行时 expected_documents 及 METADATA document_expectations 逐份登记全部授权文件，标明“预期”“仅文件名观察”与“正文已核验”；份数不符登记差异，不为凑候选份数补外部资料。
- 分开物理页码与印刷页码；取得页数和文字层，使用可用 PDF 工具，扫描件 OCR 后回原页核对表头、单位、小数点、负号与脚注。工具失败保留失败类型，不写成“未披露”。
- 从正文证券分层表、发行结果及偿付表核全称/代码/档次/初始余额，逐份连接对应档次。代码冲突未解不做跨档金额桥。
[输出]：source_index 文件行及identity_evidence、panel逐值证据定位、gaps。
[输出示例]：`source_id={完整文件SHA256}；read_status=NO_TEXT_LAYER；identity_status=IDENTITY_UNRESOLVED`。

#3 --{动作}-- [数据]
**建立报告、归集、支付与半年映射**
* 数据依赖：已读受托报告原文及累计起点条款
- 逐报告取实际报告期、归集期起止、支付日、余额时点、累计起点、边界包含约定；未知写明状态，不从披露日倒推。
- 检验连续/间隔/重叠/跨自然半年，将原报告期间映射自然半年：精确覆盖可聚合，跨界无明细标 `NOT_COMPARABLE`，同时保留原报告区间。
- 年度审计只作交叉复核或有明示修订证据的替代版本，与已覆盖受托区间不能重复相加。
[输出]：period_map、边界与重叠 gaps。
[输出示例]：`report_period=P-{原报告ID}；calendar_bucket=跨半年；allocation_method=NONE；status=NOT_COMPARABLE`。

# Step 1：统一事实与预测

#4 --{动作}-- [数据]
**抽取回收、处置、分配与剩余资产观测值**
* 数据依赖：可读原文、source_index、period_map、已核实身份
- 按 METADATA metric_naming 保留原值、原单位、定义、毛净、资产/证券层级和原页来源；每个指标单行，不混用现金与债权本金。
- 同时抽取当期/累计回收、费用税费、划转、储备、应付/实付、逐档本金余额、处置笔数与金额、剩余池户数/本息/逾期/抵押/集中度/处置阶段等实际披露项目。未披露不补齐矩阵。
- 同一事实存在不同版本时并存 source，注明修订依据和采用版本；不能一律用评级或审计替换受托值。
- 单位金额统一元、比例统一存储为0—1（报告展示乘100并标%），计数保留户/笔，转换公式留痕。只对满足同起点同口径条件的累计做差分；真实负数先复核，不能套“所有累计单调”硬规则。
[输出]：panel、assumptions、数据冲突 gaps。
[输出示例]：`metric=recovery_principal；semantic=period_flow；cash_basis=gross；value=null；quality_status=NOT_DISCLOSED`。

#5 --{动作}-- [数据]
**锁定发行原始预测及其他陈述**
* 数据依赖：发行说明书预测表及假设页、契约条款、附件内后续修订和评级
- 原始预测登记 `ORIGINAL_ISSUANCE`，保存表格、情景、基准日、金额定义、期间及累计起点；逐项对应实际指标，不能只取结论中的终值。
- 修订预测、评级情景和契约分别登记；原始预测不可被后续预测覆盖。预测若只有年度/终值，不拆半年，仅找精确共同期间或保留不可比。
- 从“预计/预测/应付/应当/不低于/保持”等候选语句与表格逐项登记可核查陈述；全量保留符合范围条目，不按叙事挑选。定性陈述无量化阈值时不得补行业标准。
[输出]：forecast_baseline、claims_verdict 初始陈述、来源链。
[输出示例]：`baseline_type=ORIGINAL_ISSUANCE；frequency=annual；halfyear_mapping=NOT_COMPARABLE`。

#6 --{动作}-- [数据]
**形成分期与累计实际预计对照表**
* 数据依赖：panel、period_map、forecast_baseline
- 按 METADATA F01—F05 计算，记录输入ID、公式、分母和状态。分期与累计并列同表，每行说明实际区间、预计区间及比较是否成立。
- 仅将无重叠且穷尽相同范围的分期相加得到累计；累计差额直接以同范围累计实际减预计；不能加总累计差额。
- 预计为零仍可报绝对差额，但百分比差异标 `ZERO_DENOMINATOR`；实际/预计缺失不取零；无法对齐时两值可展示，但禁止计算偏差。
[输出]：period_comparison；对应计算 panel 行。
[输出示例]：`period_actual=A_p；period_expected=E_p；period_diff=A_p-E_p；period_diff_ratio=(A_p-E_p)/E_p（E_p>0时，面板存0—1，展示乘100并标%）`，仅代数示意。

# Step 2：回收质量与偿付验证

#7 --{动作}-- [数据]
**分析稳定性与偏差路径**
* 数据依赖：已可比 period_comparison 与 panel
- 描述各完整可比区间实际、日均回收及区间天数；日均只辅助说明不同长度区间，不把它用于切割半年或外推未来。
- 按同长度同口径序列计算均值、样本标准差、CV及样本数。样本少于3仅展示观察、不判稳定；均值零时CV不定义，负均值或异质期间不可解释，不能报告无穷大为经济结论。
- 按累计差额符号与绝对缺口变化区分连续落后、缺口追回、缺口扩大及领先；追回不自动称“完全达标”。同时展示当期偏差以免累计掩盖近期变化。
- 单次大额处置贡献只有逐笔披露可算；否则标未披露。任何“显著/异常/稳定”档位须带来源阈值；内部观察规则单独登记，不冒充标准。
[输出]：计算 panel 行、findings、阈值 assumptions/gaps。
[输出示例]：`trend=累计仍落后且缺口收窄；depends_on=本期及前期可比累计comparison_id`（不预设案例结果）。

#8 --{动作}-- [数据]
**分别核对现金桥与逐档证券余额桥**
* 数据依赖：资产现金、信托账户、费用/税费、划转/储备、分配表、逐档应付实付和余额
- 按 METADATA F06—F09 及原文账户边界建桥，标明每项方向。内部划转在合并账户抵销，归集到支付存在跨期时通过期初/期末未划转及待付衔接，不重复计现金。
- 逐档核实期初本金、实付本金、合同认可调整及期末本金；利息实付与应付单列。非现金减记与现金本金偿付分开；不得从本金余额减少反推全额现金兑付。
- 将资产净现金与费用、优先利息、优先本金、次级、储备变化分别连通；不强行令资产回收等于证券分配。残差留数值、方向、来源及已证/待证原因。
- 覆盖指标必须有应付分母与同一支付窗口的可用现金；列计入和剔除储备的口径及储备依赖。应付缺失则不判足额、违约或现金覆盖充足。
[输出]：cash_reconciliation、security_bridge、覆盖计算 panel 行与 gaps。
[输出示例]：`residual=reported_close-calculated_close；reason_status=UNEXPLAINED`。

#9 --{动作}-- [数据]
**跟踪剩余资产池及处置效率**
* 数据依赖：panel 的剩余余额、户/笔数、资产分布、阶段、处置数据与发行基准
- 按相同指标定义比较发行池与各期剩余池；加权口径、样本退出、债权本金与回款分母分别说明。资产退出不能一概视为回收完毕。
- 在有披露数据时比较回收结构、已处置债权本金与对应回款、抵押/地区/逾期/集中度和司法阶段；错配的流量与存量不得构造处置折扣率。
- 讨论选择效应：剩余池更难处置可能因较易资产先退出；未有逐笔迁移证据时只列可解释假设，不确认质量恶化原因。
- 司法进度、抵押物价格、服务执行或费用变化须有附件原文及页码；无法量化影响时不得编贡献分解。不得外查房价、司法、行业或行情。
[输出]：剩余池比较计算、findings、assumptions/gaps。
[输出示例]：`kind=judgment；claim=剩余池变化的选择效应待核；evidence_state=INDETERMINATE；subtype=inference`。推断作为判断的子类型和证据状态记录，不另设主分类。

# Step 3：裁决、复核与交接

#10 --{动作}-- [非数据]
**逐条裁决并分离事实、计算与判断**
* 数据依赖：claims_verdict 初始陈述、已核验 panel、comparison 与桥表
- 契约按条款触发、应付、顺序与适用日期判断；原始预测按可比偏差判断“高于/低于预测”，不得把偏差直接标违约或失信。
- 按 METADATA verdict_rules 裁决，不以一半观测期替代全覆盖要求；未来未到、缺口、身份或期间不可比分别标记。
- 每条 finding 保留证据、输入计算、反向证据、范围、依赖和失效条件；不将相关变化升级为司法/市场因果。
[输出]：claims_verdict、findings。
[输出示例]：`claim_type=original_forecast；verdict=BELOW_FORECAST；legal_conclusion=不由预测偏差推导`。

#11 --{动作}-- [数据]
**验收可重跑契约与引用链**
* 数据依赖：全部十二类底稿及 METADATA quality_checks
- 校验唯一主键、外键、页码、单位、身份、期间、公式输入、计算状态及不可比拦截；从原页复核关键值并独立复算核心差额和桥残差。
- 同一附件版本、参数与公式重跑应得到同一表和稳定ID；新增披露只增版本，不静默改旧事实。保留修订前后来源和影响。
- 将已执行检查与失败检查如实登记在 report_handoff；无校验脚本时用实际可用工具或人工逐项核查并注明方式，不写“自动校验已通过”。
[输出]：经核验的底稿、未解决 gaps、可写范围。
[输出示例]：`check_id=QC-IDENTITY；result=BLOCKED；affected=逐档本金桥与对应结论`。

#12 --{动作}-- [非数据]
**封装报告交接并按授权停止**
* 数据依赖：验收后底稿、references/report-handoff.md
- 交接身份、实际截止区间、数据截止日、原始预测版本、可写结论、不可比项及缺口影响，明确每条写作结论允许用的 finding 与表行。
- 本技能独立完成上述研究、计算及判断；已有可复用上游时才按接口适配，不以保护技能完成为交接前提。未授权报告时停在 handoff，不创建报告、图表、Word或HTML。
- 用户已要求成稿即记为报告授权，加载现有 reits-report-writing 主入口，由其独立完成一篇 ABS 存续期报告；交接包不能替代成稿，Markdown与阅读版是同一篇报告的不同载体。写作中需新增指标或判断时退回本技能补证复算；新增发行评价或临界回收任务才另行转接。
[输出]：report_handoff；授权写作的转接说明。
[输出示例]：`report_authorized=false；next_action=STOP_AT_HANDOFF`。
