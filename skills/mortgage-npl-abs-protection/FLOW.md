--{abstract}--
思考路径：先核对信托与档次，再以初始本金和发行规模建立结构参照；把损失分类、抵押物、登记和城市集中度转成有证据的风险约束；最后逐支付日跑现金流瀑布，求使优先档本息足额的共同本金回收比例。账面超额本金不等于现金增信，最终回收够不等于中途利息付得出。
--{/abstract}--

# Step 0：封闭材料与身份

#1 --{动作}-- [数据]
**建立附件白名单并核实档次**
* 数据依赖：用户指定RAR及其中PDF正文。
- 只读原附件，解压至新工作目录，拒绝绝对路径或向上穿越条目；登记原文件名、大小、SHA256及页数。不得执行包内代码。
- 核实信托全称、初始起算日、信托成立日、发行缴款日、各档代码/本金/利率/预计及法定到期日，以发行结果核对实际发行参数。记录文件之间的冲突和适用时点，不静默覆盖。
- 特别检查2289267.IB与2289266.IB及7C/优先的冲突；未解时保留信托层事实，阻断档次专属测算。
[输出]：source_index.csv、identity.json、gaps.csv。
[输出示例]：source_id / file / hash / page_count / status；示例仅给字段，不填案例值。

#2 --{动作}-- [数据]
**抽取事实、条款和预测**
* 数据依赖：已登记的发行说明书、评级报告、发行结果及受托报告。
- 原样记录数值、单位、基准日、定义、表头、脚注及PDF页序。不同评估日期、余额口径、报告机构分别建观测；保留披露值与自算值。
- 固化发行九项数据字段，按METADATA建立缺口；不得从另一产品、另一期预测、另一评级机构补同名字段。
[输出]：panel.csv、terms.csv、forecast_rating.csv。

# Step 1：九项资产与保护分析

#3 --{动作}-- [数据]
**核算发行规模、本金倍数和优劣后分层**
* 数据依赖：初始入池未偿本金B0，各档实际发行本金，初始优先本金S0及劣后本金J0。
- 计算总发行I0、B0/I0、B0/S0、S0/I0、J0/I0、S0/J0；多优先档分别列档并标合计边界。
- 并列B0-I0、(B0-I0)/I0、(B0-I0)/B0及劣后厚度J0/I0。明确各公式分母，避免把两种超额抵押率混用。
- 将未偿本息总额与未偿本金分开，不用贷款合同原始金额作B0。
[输出]：issuance_metrics.csv、protection_matrix.csv。

#4 --{动作}-- [数据]
**核对损失类、抵押率与登记状态**
* 数据依赖：分类表、抵押评估表及权利登记表。
- 单列损失类贷款本金L、披露比例、自算L/B0及差额。若仅有占比，推算金额标derived，记录披露四舍五入误差；不称精确披露金额。
- 抽取初始抵押率及原始分子/分母/日期；抽取加权平均最新抵押率，核对是否为初始起算日未偿本金/入池评估价值以及权重。
- 有逐笔数据时分别计算Σw_i(B_i/V_i)、ΣB_i/ΣV_i；二者不能替代。无逐笔时不得用组合本金/组合评估值声称重算了加权平均LTV。
- 列抵押预告登记笔数、笔数比例、本金金额、本金比例及分母；与正式登记、未登记、其他状态分别列，核验是否互斥穷尽。占比口径缺失就标不可比。
[输出]：issuance_metrics.csv、rights_risk.csv、reconciliation.csv。

#5 --{动作}-- [数据]
**核对城市前十、账龄及中债资信预测**
* 数据依赖：城市分布、账龄/拖欠分布及中债资信报告。
- 以原文定义的资产所在地为维度，不以借款人地址或服务行所在地替代；按本金降序列前十金额、比例、CR10和其他。只有省份分布就报告城市缺失；只有部分城市不得声称完整前十。有并列第十名时说明截断方法。
- 区分贷款发放至基准日的存续账龄、逾期天数、不良形成时间、违约账龄、剩余期限；分别保留区间分布和披露加权平均，不以区间中点当实际均值。
- 中债资信单列预测机构、报告日期、情景/压力等级、回收金额、回收率分母、毛净口径、费用、回收时点、折现及本金/本息口径。初始预测与跟踪修订各自保留；禁止将中诚信预测写成中债预测。
[输出]：city_top10.csv、age_profile.csv、forecast_rating.csv、issuance_metrics.csv（九项覆盖完整性）。

#6 --{动作}-- [非数据]
**评价结构保护的有效条件**
* 数据依赖：#3—#5及合同现金流分配条款。
- 逐项说明保护来源、受益档、金额/比例、触发条件、失效路径；用处置折价、权利实现与时间成本解释为何本金覆盖不能保证现金足额。
- 按原文识别税费、服务费、受托费、储备补足、优先利息/本金、劣后分配顺序和触发事件；未披露顺序不能套通用瀑布。
- 对地域集中、预告登记、账龄及损失类给出证据约束下的判断。不得把损失类金额等同最终损失，不得凭初始LTV推出现时抵押价值。
[输出]：protection_matrix.csv、findings.csv。

# Step 2：优先档临界回收率

#7 --{动作}-- [数据]
**建立模型边界和参数登记**
* 数据依赖：terms.csv、初始面板；若测剩余则接入定期跟踪锁定面板。
- 分别建立发行时全生命周期模型和截至期末的剩余模型，不混用已收回现金和未来回收。
- 明确“每笔平均回收百分比”：共同r情景为每笔实际未偿本金×同一r；总体回收额/B0是本金加权回收率；简单算术均值不能唯一决定总现金。无逐笔数据时标明组合等比例情景。
- 登记时间分布、固定/浮动利率、计息规则、税费/变动费用、其他收入、储备及最终日，所有缺失单列；仅本金静态公式可得时，不输出动态本息足额结论。
[输出]：model_inputs.csv、assumptions.csv、gaps.csv。

#8 --{动作}-- [数据]
**逐支付日求解并复算**
* 数据依赖：#7，references/model-method.md。
- 建立带参数的可重算脚本或模型；对r∈[0,1]计算每期可用现金、费用、优先应付及实付利息/本金、欠息、储备、期末余额及最终短缺。
- 先检验0与1可行性、现金桥和本金桥，再检验可行性单调。满足条件才二分搜索；不满足时分析不连续触发、改用分段搜索，禁止照搬二分。
- 输出r*附近可行/不可行两点及误差界，足额及时付息与法定最终本金两项分别判定；无[0,1]内解时说明100%本金回收下仍不能满足的约束。
- 单列本金静态下限S0/B0及固定日期/固定成本静态近似，并标明与动态结果差异。不得把下限当最终答案。
[输出]：model_cashflows.csv、breakeven_scenarios.csv、model_validation.csv、可重算模型文件。

#9 --{动作}-- [数据]
**进行时间、费用及尾部敏感性**
* 数据依赖：#8、包内已披露预测和剩余资产特征。
- 以文件预测为基准；延迟、费用或抵押折价情景作为独立研究假设登记，不能声称来自原文。
- 比较同回收总额但前后移的利息短缺、额外费用、r*变化；延迟越过法定最终日须判违约约束不可满足，不简单延期。
- 与中债预测比较前先统一本金/本息、毛净、时点和折现口径；不一致则双列解释而不硬减。发行模型与剩余模型分别列头寸。
[输出]：breakeven_scenarios.csv、findings.csv、claims_verdict.csv。

# Step 3：验证与写作移交

#10 --{动作}-- [非数据]
**闭合证据、计算与判断**
* 数据依赖：全部底稿。
- 检查九项是否覆盖且缺失明确、金额比例能否对账、初始/最新边界及档次代码一致。
- 从每条finding反查观测、来源和模型输入；计算与披露不符时给两值、差额、可核对原因，原因未知就明示未知。
- 按report-handoff整理可用表格、结论、反证、限制与章节映射；仅在另行要求成稿时调用写作。
[输出]：report_handoff.json、完整性检查结果；本技能不直接生成正式报告。
