# 独立发行研究、可选定期跟踪及reits-report-writing接口

## 范围

本技能独立研究发行资产质量、结构保护及优先本息临界回收率，用户要求成稿时交给 `reits-report-writing` 生成单独发行资产质量与优先保护报告。交接声明 `report_type=npl_issuance`、`writer_skill=reits-report-writing`，填写report_title、output_dir、report_authorized和evidence_scope；report_authorized仅在用户已要求成稿时为true。报告按写作契约独立命名为report_{code}_npl_issuance.md，代码未核验时用case_id。默认只包含本技能底稿，不要求先运行npl-abs-periodic-monitor。只有用户要求共享存续底数时，才接入定期跟踪的可选底稿；完整存续研究另行生成npl_monitor独立报告。本次发行报告与存续报告始终分别交付，不合并成篇。用户只要技能时停止于技能交付；用户要分析但未要成稿时停止于底稿。

保持同一case_id与来源哈希，合并来源目录但不去掉不同版本；两技能观测使用observation_id关联。保留发行基准、报告截止、回款区间及支付日，不能因同属一期就混成同一时点。

## 接入可选定期跟踪时的数据适配（发生交接则强制）

两技能共享case_id；source_index均为文件级目录，source_id使用同一文件字节的完整小写SHA256；panel中的比例统一为0—1，仅在报告展示时乘100并标%。保留原始值、原始单位、观测ID和转换公式；百分点变化与比率分别标明，倍数与覆盖倍数不按百分比转换。

逐值证据保存在panel的source_id、PDF物理页、表格、原值、原单位及指标口径中，原文陈述另保留页码和摘录。以文件哈希和物理页、指标、值、单位、期间、口径建立显式映射，两边observation_id分别保留。共同字段和单位一致不代表整张CSV可直接拼接；额外字段、期间与口径仍按两边METADATA验证。旧版D-/S-标识与0—100比例底稿须显式迁移并留转换记录，不能直接当作新版输入。

交接adapter_crosswalk.csv：`case_id,from_skill,from_table,from_id,to_skill,to_table,to_id,file_sha256,source_page,metric,from_unit,to_unit,conversion_formula,basis_check,status`。状态、finding_type/kind、身份字段和引用数组按两边METADATA进行语义适配，不覆盖原记录；未确认的映射禁止参与跨技能计算。

## 写作输入

- IN-1事实底稿：source_index.csv、panel.csv、issuance_metrics.csv、protection_matrix.csv及九项分表；已核验事实、文件预测和独立假设分别标记。period_summary及period_comparison仅按需共享存续底数，不列为发行报告必备输入；完整逐期研究由独立存续报告承载。
- IN-2模型：可执行代码或有公式模型、formula_registry.csv、model_inputs.csv、model_cashflows.csv、breakeven_scenarios.csv及model_validation.csv；无完整动态输入只承接静态下限及不可测边界，不伪造完整模型。引用必须从finding的formula_ids连至公式及输入，再到观测和来源，不能只写“见模型”。
- IN-3假设：assumptions.csv，带取值、依据、来源、敏感性及状态。
- IN-4结论/裁决：findings.csv及claims_verdict.csv，每项含证据、反证、依赖、确定性和失效条件。
- IN-5来源及缺口：source_index.csv、gaps.csv；所有金融来源只能为附件内文档，原文没有URL时填离线不适用，不搜索外部补链。

对齐既有report-writing的等价底稿验收，不为形式要求伪造缺失模型或文件。写作层不得新造数字、改变分母、把假设写成披露、把推断写成已证实原因；需要新计算时退回相应上游并更新引用。正文不展示内部状态码，但须准确表述未披露、未核实、口径不可比。

## ABS写作章节映射（仅后续成稿时采用）

| 章节 | 取数技能/内容 | 必须保留的边界 |
|---|---|---|
| 结论及资料范围 | 本技能已裁决finding | 档次代码核验与材料截止 |
| 发行资产质量 | 九项指标、城市表、权利登记及账龄 | 时点、权重、抵押率分母与预测机构 |
| 分层和保护机制 | 本技能结构保护及合同瀑布 | 本金倍数不等于现金增信 |
| 评级预测及口径 | 本技能forecast_rating | 原始/修订、毛净、本金/本息及折现分开 |
| 临界回收与敏感性 | 本技能模型 | 共同r、时点、费用、及时付息及最终清偿 |
| 风险和结论成立条件 | 本技能证据、假设及缺口 | 事实/计算/判断分层；不给未取证的存续期结论 |
| 可选共享存续底数（仅按需引用） | 定期跟踪已核验且与发行判断有关的底数 | 不扩展为完整存续章节；逐期回收、兑付桥及预测对比另交独立存续报告 |
| 附录 | 来源、公式、假设、缺口、核验 | 不能用附录掩盖影响核心判断的限制 |

后续单独发行报告必须实际嵌入九项指标表、结构保护表、预测口径表及适用的临界回收情景表和结论文字，表内区分披露事实/计算差异，正文标明判断及依据。临界回收表列模型边界、r*、及时付息、最终本金、限制日期、预测可比性。逐期对比表在另行独立存续报告中交付，本篇仅按需引用已核验底数；原报告未披露就写未披露，不为“九项齐全”填数。写作中保持findings.kind的fact/calculation/judgment语义，不在正文展示内部代码。

沿用reits-report-writing的结论先行、来源就近、图表口径说明和事实核验；不套REIT七章、租金指标、强制反转结论或固定字数配额。通过report_handoff.json声明ABS章节映射与适用例外；该文件是输入适配，不替代实际调用写作技能。非核心缺口限定相关结论后继续可支持部分，档次身份未解则不输出该档专属模型判断。

## 案例隔离区：建鑫7（仅用户明确选择时启用）

以下为历史任务配置，不是本技能默认值，也不是正文已核验事实：

- archive_path：从本次runtime输入取得；历史basename为`22建鑫7优先（2289267.IB）.rar`，不预设个人目录；requested_code：`2289267.IB`。
- 身份正文核验通过后的验收标题为《22建鑫7优先发行资产质量与优先档保护机制分析报告》。如优先档身份仍未解决，标题改为《22建鑫7发行资产质量与保护机制分析报告（优先档身份待核验）》，不得用标题预先确认请求代码为优先档。
- 历史文件名清单观察为22份PDF，含发行说明书、发行结果、初始及跟踪评级、总第1—9期受托报告与年度审计材料；实际数量、版本和内容必须重新检查。
- 已知文件名线索：多个文件名写`2289266.IB`优先，部分`2289267.IB`写7C；不能据此定优先档。须从正文核验信托全称、两代码、档次名称和分层属性，并保留原页证据及冲突记录。
- 用户将“发行说明书”称作“招募说明书”时，保留双方名称并核实版本。不为案例预填任何金融数值，不把文件名线索迁移成其他产品规则。
