# 共同本金回收率的测算边界

## 1. 定义待求量

令B_i为同一基准日第i笔贷款未偿本金，B=ΣB_i。情景假设每笔本金回收比例均为r，则回收本金总额=rB。此时本金加权平均比例与简单平均都为r；若只有简单平均(Σr_i)/n而各笔本金不同，总回款ΣB_i r_i无法唯一确定，禁止输出唯一临界值。无逐笔明细时仅能称组合等比例回收情景，不能声称验证每笔真实回收率。

贷款本金以外的回收利息、罚息、抵押物处置净款须辨别是否已包含本金，防止重复。若评级给总回收本息/总债权账面值，不可直接与本模型r比较。

## 2. 静态参照

发行时本金静态下限r_principal=S0/B0，只表示忽略利息和费用、无其他现金来源时的本金需求比例，不是本息临界回收率。

固定支付时点、固定总利息I、费用F及可用于优先支付的外部现金C时，静态近似r_static=(S0+I+F-C)/B0；若负值，可行下限截为0并说明。该式不能处理随本金摊还变化的利息、比例收费、储备、分配触发或中途资金缺口。没有I/F依据时只给符号公式及缺口，不能默认为0。

若费用确实为固定F0+α×本金回款且其他条件不随r变化，可用(S0+I+F0-C)/[(1-α)B0]作为条件近似；须有α的文档或显式假设依据。

## 3. 动态模型

以合同实际支付日为时间步，并明确回款截止、划转和支付日。给每笔/组合回收的时间权重w_i,t，Σ_t w_i,t=1；基础本金回款rΣ_i B_i w_i,t。时间权重只能来自本次授权材料范围内的预测或独立登记的假设，不能把年度预计直线分摊后称原文半年预测。

每期先计算可用现金：期初现金+当期已划转回款+其他可用收入+允许释放的储备。按原文顺序分配税费、服务费、受托费、储备、各优先档利息与本金、劣后现金；本金/收益账户能否互补、递延费用/欠息是否累积或计息，均依条款，不默认允许。

按该档合同年化票息及日数规则计算应付息，通常从期初实际未偿本金出发，但须按实际条款确认分段摊还和生效日。发行说明书的询价区间不代替发行结果确定票息；缺浮息未来路径时登记假设，不编造基准利率。不得用本期付息后的期末本金乘全期利率。

现金桥：期末可用现金及单列受限储备合计=期初两者合计+全部实际现金流入-全部对外流出；内部储备转移不得两边重复计入。证券本金桥：期初本金-本金偿付-依法核销/其他调整=期末本金；其他调整必须单列且不视为现金兑付。保留披露数、自算数及差额。

可行性要求：（a）每个必须付息日实付利息达到合同应付利息，未允许递延的欠息为0；（b）优先本金不晚于法定最终日清零，有契约强制中途本金时还须按其到期日支付；（c）费用、储备和触发条款均满足且现金不透支。预期到期日未实现与法定违约分别表述。未来本金仅按实际合同要求视为到期；预测本金摊还计划不自动构成契约强制本金。

## 4. 求解

定义G(r)=上述全部约束均满足。检查r=0、r=1，从条款分析回款增加对费用/储备/触发的影响；有限抽样只用于发现反例，不证明全区间单调。单调且存在可行点时二分求下确界，保留一侧不可行r_lo与另一侧可行r_hi及r_hi-r_lo。r=0已可行时报告临界为0并列外部现金来源。仅在已证明G单调不减时，r=1不可行才说明[0,1]无可行解。触发不连续但仍单调且可行性精确判定时可以二分；非单调或单调性无法确认时，按已知触发边界分段，检查边界本身和两侧及各段内部极小点。不能穷尽时只报告已检出的可行区间和精度，不把r=1失败或网格均失败当作全区间无解证明。不能输出超过100%的“贷款本金回收率”作为可实现结论。

金额容差按数值精度声明，比例容差按求解设定声明，两者分开。检查r_lo的限制日期和缺口及r_hi现金桥，不能仅看期末余额。提交实际模型代码/公式及输入表，不以语言描述冒充运行结果。

## 5. 逐支付日可执行算法

先把条款编译为按条件选择的有序支付节点，而非固定套用某个市场瀑布。输入至少含：贷款本金及回款权重、实际到账日与所属账户、支付日历、各档期初本金、计息分段与日数规则、票息路径、各项费用的计提/支付规则、储备目标/释放规则、触发条件及评估时点、允许跨账户划转规则、欠款递延/计息规则、法定最终日。缺失项标缺口，不以零或“常见条款”替代。

状态为每个账户现金C[a]、受限储备R[a]、各档未偿本金P[k]、欠息A[k]、递延费用D[j]及触发状态H；所有余额在一次simulate调用内重新初始化，不能沿用另一r的状态。以支付日为外层循环；期内实际摊还、生效日或浮息重置日需要分段时先建立事件子区间。

```text
simulate(r, inputs):
  校验 0<=r<=1；权重非负；每笔全部时点（含最终日后）的权重合计为1
  初始化 C,R,P,A,D,H；保存本金及现金初值；ok=True
  for t in 完整支付日历（至少包含法定最终日）:
    保存 C0,R0,P0,A0,D0；本期所有实付清零
    按到账日/划转截止日把 r*sum(B[i]*w[i,t]) 记入指定账户
    最终日后回款单列，不能提前计入最终日可用现金
    其他收入仅计已登记且不与本金回款重复的金额
    I[k] = sum(子区间实际未偿本金[k,s]*票息[k,s]*合同年化日数分数[s])
    应付息[k] = I[k]+A0[k]+按条款计算的欠息利息
    应付费[j] = 本期条款计提额[j]+D0[j]（核对是否同属到期费用）
    在合同指定时点计算触发H；按H选择瀑布（需期内重测时逐节点重测）
    for 节点 in 合同有序瀑布:
      按条款执行获准账户划转/储备释放（内部转移现金守恒）
      if 节点为费用或利息:
        pay = min(该节点到期未付额, 该节点可合法调用的现金)
        依条款规定的账户扣减顺序扣款；记录对外实付
      if 节点为本金:
        应付本金 = 按触发/顺序/计划约束计算的金额，且不超过P[k]
        pay = min(应付本金, 可合法调用现金)；扣现金；P[k] -= pay
        多档顺序或同比例分配严格按条款；不得每档各用一遍总现金
      if 节点为储备补足:
        transfer = min(max(目标储备-R,0), 合法可用现金)
        C -= transfer；R += transfer（不记对外费用）
      if 节点为劣后分配:
        仅支付条款允许的余额；扣现金并计对外流出
    A[k] = 应付息[k]-实付息[k]；D[j] = 应付费[j]-实付费[j]
    按条款区分允许递延欠款与违约；如有本金调整，单列且不算现金偿还
    检验所有账户非负、储备要求和触发义务
    检验 sum(C+R)-sum(C0+R0) = 实际外部流入-所有对外实付
    检验 P0[k]-本金实付[k]-本金调整[k] = P[k]
    对每个必须付息日：ok &= 该日合同到期未付息<=金额容差
    如该日存在契约强制本金：ok &= 当日强制本金未付额<=金额容差
    在各档法定最终日：ok &= P[k]<=金额容差且所有最终到期本息已付
    任一期失败保留在ok中，后期补付不能抹掉历史及时支付失败
    保存信托汇总现金桥、账户明细、各档状态和首次失败日期/原因
  return ok且所有契约到期约束满足, 完整逐期记录
```

允许递延的利息不能误判为该日必须支付；但其最终到期要求仍须满足。合同若要求中间本金偿付，同样逐期检验该项到期本金，而不只看最终日。金额容差仅判断残差，不得将小额负现金当作融资或冲销欠款。实际模型须实现每个有来源的费用/触发函数；条款适配或所需输入未覆盖时拒绝计算受影响的动态结果，仅交付可支持的静态参照与缺口。以上伪代码是实现顺序，不是可直接运行的脚本或已运行的交易模型。

已确认单调不减时的求解为：先运行G(0)，若真则返回0；否则运行G(1)，若假则报告区间无解；若真则置lo=0、hi=1，循环mid=(lo+hi)/2，G(mid)真则hi=mid，否则lo=mid，直到hi-lo<=比例容差。最后重新运行lo、hi并分别保留失败约束与通过明细。金额容差与比例容差分列；未达到区间宽度或最大迭代数耗尽时标未收敛。

## 6. 人工合成最小验算（不属于任何产品事实）

本节所有数字、日历和规则均为人工构造的算法测试，金额单位为测试元，不来自建鑫7或附件，不得进入真实事实面板或报告引用。设B=100、优先本金S=60，两个支付期年化日数分数各0.5、票息0.10；各期费1且优先支付，期初现金及储备均为0，无其他收入/欠息利息，每期按费→优先利息→全部剩余现金偿优先本金分配。本金回款权重(0.5,0.5)，第二期为法定最终日，全部利息当期到期。

- 第一期流入50r，付费1、利息60×0.10×0.5=3，本金实付50r-4，期末本金64-50r（适用本验算临界邻域）。现金桥50r-1-3-(50r-4)=0。
- 第二期流入50r，付费1、利息(64-50r)×0.05=3.2-2.5r。最终本金清零条件为50r-1-(3.2-2.5r)>=64-50r，因此r* = 68.2/102.5 = 0.6653658536585366。静态本金下限为0.6，二者不同。
- r=0.6653：首期期末本金30.735；二期利息1.53675，本金实付30.72825，最终短缺0.00675，失败。r=0.6654：首期期末本金30.73；二期利息1.5365，本金实付30.73后留现金0.0035，两期及时付息并最终清偿，通过。区间宽0.0001，金额判定容差须小于0.0035，例如0.000001测试元。
- 将相同总回款的权重改为(0,1)，即使r=1，首期现金0也付不出到期利息3及费用1；不允许借款或延期，因此失败。这验证总回款足够不能代替逐期可行性。真实模型仍须独立检验其条款与输入，不能把此测试结果外推。

## 7. 剩余模型

以已核对报告期末为起点，未来本金基数B_rem必须为剩余可追索未偿本金并核对已处置但未核销等口径。需求为S_rem及未来利息、费用；现金C_rem只取可用于该档的真实余额，排除已支付、已计入累计回款又加入现金的重复项，受限储备按释放条款处理。单独求r_rem，不用r_rem与初始中债预测直接比较。

若该优先档已足额兑付，未来需求为0，记录“优先档剩余本息需求不适用”；不得据此得出资产池无风险或再计算负回收率。初始模型仍可回顾，劣后和剩余资产另评价。

## 8. 最低敏感性与限制

分别检验回款后移、费用上升和尾部回收下降对利息短缺/本金最终日/r*的影响；有实际材料就据实取值，独立情景用assumed标记。未来分布未知时报告r*(时间分布、费用、利率等条件)，不给无条件唯一数字。情景结果是计算，现金流解释与保障评价是判断，两者分列。
